## 外层包

Publisher HTTP 成功响应外面仍是统一包：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

`POST /api/v2/flow/project` 创建项目时 HTTP 状态码是 `201 Created`，响应体仍按统一包返回，`data` 里放 `WorkflowProjectResponse`。

前端 `aws.ts` / `assets.ts` / `flow.ts` 读的是 `data`。

## 一、COS 预签名上传

### `POST /api/v2/cos/presign`

用途：首页普通附件和语义槽位附件上传前，先拿到可直传的 COS/S3 预签名地址。

认证：按前端 `useHttp()` 统一带业务 JWT。首页未登录时应先打开登录弹窗，不要让上传接口匿名落库。

请求体：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `filename` | string | 必填。原始文件名，用于提取扩展名 |
| `content_type` | string | 必填。文件 MIME 类型，例如 `image/jpeg`、`video/mp4` |
| `file_type` | string 或空 | `image` / `video` / `audio`，不传则落到通用 uploads 路径 |

示例：

```json
{
  "filename": "role.png",
  "content_type": "image/png",
  "file_type": "image"
}
```

成功时 `data` 形状：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `presigned_url` | string | 前端直接 `PUT` 文件的地址 |
| `object_key` | string | COS/S3 对象键 |
| `cdn_url` | string | 上传成功后交给 Composer / Agent 的 CDN URL |
| `expires_in` | number | 预签名地址有效秒数 |

示例：

```json
{
  "presigned_url": "https://bucket.example.com/uploads/xxx?signature=...",
  "object_key": "images/2026/09/role_xxx.png",
  "cdn_url": "https://cdn.example.com/images/2026/09/role_xxx.png",
  "expires_in": 900
}
```

前端上传顺序：

```text
postUploadFile(file)
  → maybeCompressUploadImage(file)
  → getPresignedUrl(file.name, file.type)
  → POST /api/v2/cos/presign
  → PUT presigned_url
  → remoteUrl = normalizeCdnResourceUrl(cdn_url)
```

约束：

- 浏览器 `File` 不进入 handoff，也不直接交给 Agent。
- 预签名地址快过期或 `PUT` 返回 403 时，可以重新取 presign 再传。
- 上传中附件要标记 `isUploading = true`，发送按钮不可用。
- 上传失败附件要标记 `hasError = true`，不能静默丢掉后继续发送。

## 三、语义槽位附件入库

### `POST /api/v3/assets/library`

用途：用户明确选择角色、产品、品牌视觉槽位时，把已上传的图片或视频写入个人素材库。普通上传不自动入库。

认证：必须带 `Authorization: Bearer <__opencreator_jwt>`，素材归属以后端 `get_authenticated_user()` 为准。

入库触发规则：

```text
attachment.type 是 image 或 video
并且 tag 能映射到 library_kind
```

映射：

| Composer `tag` | `library_kind` |
| --- | --- |
| `character` | `character` |
| `product` | `product` |
| `style_reference` | `brand_visual` |

请求体：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `library_kind` | string | `character` / `product` / `brand_visual` |
| `source_kind` | string | 首页上传固定为 `uploaded` |
| `media_type` | string | `image` / `video` |
| `url` | string | 必填。COS/CDN 远端 URL |
| `thumbnail_url` | string 或空 | 视频封面或缩略图 |
| `name` | string 或空 | 原始文件名，最长 255 |
| `upload_context` | string 或空 | 首页普通槽位上传用 `home_composer_attach` |
| `resource_info` | object 或空 | 宽高、格式等资源信息 |
| `aspect_ratio` | string 或空 | 原始宽高比 |

`resource_info`：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `width` | number 或空 | 和 `height` 同时出现 |
| `height` | number 或空 | 和 `width` 同时出现 |
| `format` | string 或空 | 例如 `png`、`mp4` |
| `file_size` | number 或空 | 大于等于 0 |
| `codec` | string 或空 | 视频编码 |

示例：

```json
{
  "library_kind": "character",
  "source_kind": "uploaded",
  "media_type": "image",
  "url": "https://cdn.example.com/images/role.png",
  "thumbnail_url": "https://cdn.example.com/images/role.png",
  "name": "role.png",
  "upload_context": "home_composer_attach",
  "resource_info": {
    "width": 1024,
    "height": 1024,
    "format": "png"
  },
  "aspect_ratio": "1:1"
}
```

成功时 `data` 形状：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `asset_id` | string | 素材库 id |
| `library_kind` | string | 素材类型 |
| `source_kind` | string | `uploaded` |
| `media_type` | string | `image` / `video` |
| `url` | string | 原资源 URL |
| `thumbnail_url` | string 或空 | 缩略图 |
| `name` | string 或空 | 展示名 |
| `upload_context` | string 或空 | 上传来源 |
| `metadata` | object 或空 | 服务端补充元信息 |
| `created_at` | string | 创建时间 |
| `updated_at` | string 或空 | 更新时间 |

约束：

- 入库失败只设置 `librarySaveFailed = true` 并提示重试，不等于附件上传失败。
- 已上传的远端附件仍然可以进入 handoff 并发送给 Agent。
- 入库成功后要刷新个人素材库相关 query cache。

## 四、创建空 flow project

### `POST /api/v2/flow/project`

用途：首页点击发送或 Skill 卡片“立即使用”时，先创建一张空画布容器。

认证：必须带 `Authorization: Bearer <__opencreator_jwt>`。

请求体：`SaveWorkflowProjectRequest`。

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `project_name` | string | 必填。首页默认 `Untitled` |
| `nodes` | array | 必填。首页创建时为空数组 |
| `edges` | array | 必填。首页创建时为空数组 |
| `parent_flow_id` | string 或空 | 模板或复制来源 |
| `allow_reshare` | boolean 或空 | 缺省 `true` |

首页默认 payload：

```json
{
  "project_name": "Untitled",
  "nodes": [],
  "edges": []
}
```

成功时 HTTP 状态：

```text
201 Created
```

成功时 `data` 形状：`WorkflowProjectResponse`。完整项目读取字段继续沿用第 02 章 [03-接口形状.md](../02-画布登录门禁与项目加载/03-接口形状.md)，首页创建后最关键字段是：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `flow_id` | string | 新画布 id，后续写入 handoff 并跳转 |
| `user_id` | string | 项目 owner |
| `nodes` | array | 首页创建时为空 |
| `edges` | array | 首页创建时为空 |
| `allow_reshare` | boolean | 是否允许再分享 |
| `parent_flow_id` | string 或空 | 来源 flow |
| `last_view_time` | string 或空 | 最近查看时间 |
| `details` | object 或空 | 项目详情 |
| `created_at` | string | 创建时间 |
| `updated_at` | string | 更新时间 |
| `time_zone` | string 或空 | 时区 |

`details`：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `flow_id` | string | 详情所属项目 id |
| `project_name` | string | 画布标题 |
| `snapshot` | object 或空 | 截图信息 |
| `created_at` | string | 创建时间 |
| `updated_at` | string | 更新时间 |
| `time_zone` | string 或空 | 时区 |

成功后的前端动作：

```text
postSaveFlow()
  → queryClient.setQueryData(flowKeys.detail(savedFlowId), res)
  → markFreshFlow(savedFlowId)
  → markFreshAgentSession(savedFlowId)
  → invalidate 项目列表和最近项目
```

失败语义：

| 场景 | 行为 |
| --- | --- |
| 未登录或 JWT 无效 | 打开登录弹窗或返回 401 |
| 服务端返回业务错误 | `onFailure(errorText)` 展示错误并恢复 `createLoading` |
| 网络异常或未知错误 | `onError()` 展示创建失败并恢复 `createLoading` |

## 五、首页发送整理形状

首页 `handleSend()` 整理的是首轮 Agent 输入，不是 workflow run 请求。

发送前检查：

| 条件 | 行为 |
| --- | --- |
| 未登录 | 打开登录弹窗，登录成功后重试 `handleSend()` |
| `createLoading = true` | 直接停止 |
| 普通附件上传中 | 直接停止 |
| 槽位附件上传中 | 直接停止 |
| 存在 `hasError` 附件 | 提示移除失败附件，停止 |
| Agent 模型权限 loading | 发送按钮不可用 |
| 无文本、无 Hook、无可发送附件 | 发送按钮不可用 |

整理出的核心字段：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `submittedAgentModelId` | string 或空 | 用户发送瞬间选中的模型 |
| `isSkillOnly` | boolean | 没有文本但有 Hook/Skill |
| `outboundText` | string | 普通场景是 `composerText`，Skill-only 是零宽文本 |
| `readyHandoffAttachments` | array | `homeSlotAttachments + readyAttachments` |
| `homeHookPayload` | object 或空 | Hook/Skill 配置 |
| `richTextHtml` | string 或空 | mention 富文本 |
| `analyticsContext` | object 或空 | Skill 卡片直达归因 |

Skill-only 规则：

```text
没有 composerText
但有 homeHookPayload
  → outboundText = "\u200b"
  → richTextHtml = skill mention
```

注意：这一步不创建 workflow run，不发 `/api/v2/flow/runs`，也不直接改画布节点。

## 六、首页到画布 handoff

### `sessionStorage: opencreator:home-agent-handoff`

用途：当前浏览器会话内，把首页首轮 Agent 输入交给 `/canvas/{flowId}` 的 `AssistantProvider`。

这不是 HTTP 接口，也不是服务端队列。

payload：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `flowId` | string | 必填。必须等于当前画布 `flowId` 才能消费 |
| `text` | string | 必填。普通文本或 Skill-only 零宽文本 |
| `attachments` | array | `ComposerExternalAttachment[]` |
| `agentModelId` | string 或空 | 用户选择的 Agent 模型 |
| `hook` | object 或空 | `ChatHookConfigPayload` |
| `richTextHtml` | string 或空 | mention 富文本 |
| `analyticsContext` | object 或空 | Skill 卡片直达分析上下文 |
| `createdAt` | number | 保存时自动写入的毫秒时间戳 |

`hook` 形状：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `hook_id` | string | Hook/Skill id |
| `channel_id` | string | 频道 id |
| `duration` | number | 时长 |
| `aspect_ratio` | string | 宽高比 |
| `main_image_model` | string | 主图模型 |
| `shot_image_model` | string | 分镜图模型 |
| `shot_video_model` | string | 分镜视频模型 |
| `bg_audio` | boolean | 是否生成背景音 |
| `on_caption` | boolean | 是否加字幕 |
| `hook_name` | string 或空 | 展示名 |
| `hook_category` | string 或空 | 分类 |
| `hook_pick_surface` | string 或空 | `recommended` / `all` |
| `hook_position_index` | number 或空 | 展示位置 |

示例：

```json
{
  "flowId": "flow_xxx",
  "text": "帮我做一个角色海报",
  "attachments": [
    {
      "type": "image",
      "url": "https://cdn.example.com/images/role.png",
      "tag": "character",
      "assetSlotKind": "character",
      "fileName": "role.png"
    }
  ],
  "agentModelId": "model_xxx",
  "hook": null,
  "richTextHtml": "<p>帮我做一个角色海报 <span data-type=\"mention\" data-mention-source=\"attachment\">@role.png</span></p>",
  "createdAt": 1790554500000
}
```

函数语义：

| 函数 | 行为 |
| --- | --- |
| `saveHomeAgentHandoff(payload)` | 写入 `sessionStorage`，自动补 `createdAt` |
| `peekHomeAgentHandoff(flowId)` | 只读取相同 `flowId` 的 payload |
| `acknowledgeHomeAgentHandoff(flowId, createdAt)` | 同时校验 `flowId` 和 `createdAt`，匹配才删除 |
| `consumeHomeAgentHandoff(flowId)` | 读取后立即确认删除 |
| `shouldRetryHomeAgentHandoff(status, attempts, maxAttempts = 2)` | 只有 `not_started` 且次数不足时重试 |

约束：

- JSON 解析失败要删除坏数据。
- `flowId` 不匹配时不能消费，也不能误删。
- accepted 后才能确认删除；`not_started` 可按上限重试。
- 同一个 handoff 默认最多尝试 2 次。

## 七、画布侧 Agent 消费 handoff

消费位置：`AssistantProvider`。

消费条件：

| 条件 | 要求 |
| --- | --- |
| `agentModelAccess` | 不能是 `loading` |
| `chat.isRunning` | 必须为 `false` |
| `isLoadingMessages` | 必须为 `false` |
| `peekHomeAgentHandoff(flowId)` | 必须存在 |
| 同一 `flowId:createdAt` | 尝试次数小于 2 |

消费动作：

```text
peekHomeAgentHandoff(flowId)
  → normalizeAgentModelId(pending.agentModelId)
  → setSelectedAgentModelId()
  → pendingFilesRef.current = attachments 转为 ChatAttachmentPayload[]
  → pendingHookConfigRef.current = hook
  → pendingRichTextHtmlRef.current = richTextHtml
  → sendMessage({ content: [{ type: "text", text }] }, { source: "home_handoff" })
  → accepted 后 acknowledgeHomeAgentHandoff(flowId, createdAt)
```

`attachments` 转给 Agent 前的字段名会从前端 camelCase 变成请求态 snake_case：

| handoff 字段 | Agent 请求态字段 |
| --- | --- |
| `assetSlotKind` | `asset_slot_kind` |
| `assetPickerSessionId` | `asset_picker_session_id` |
| `assetPickerSurface` | `asset_picker_surface` |
| `assetPickerSource` | `asset_picker_source` |
| `assetPickerActionLocation` | `asset_picker_action_location` |
| `assetSelectionSource` | `asset_selection_source` |
| `assetChannelId` | `asset_channel_id` |
| `controlSource` | `control_source` |
| `controlAnnotationCount` | `control_annotation_count` |
| `previewSessionId` | `preview_session_id` |
| `controlWorkbenchSessionId` | `control_workbench_session_id` |
| `sourceNodeTag` | `source_node_tag` |
| `sourceNodeId` | `source_node_id` |
| `sourceResultId` | `source_result_id` |
| `sourceOutputIndex` | `source_output_index` |

投递状态：

| 状态 | 行为 |
| --- | --- |
| `accepted` | 删除 handoff，结束 |
| `not_started` | 清空 pending refs，未超过次数时 750ms 后重试 |
| `rejected` | 清空 pending refs，不继续重试 |
| 抛异常 | 清空 pending refs，记录错误，不删除 handoff |

## 八、首页 Skill 卡片直达

首页 Skill 卡片的“立即使用”仍然走同一套创建 flow 和 handoff，不另起一套接口。

差异：

| 字段 | Composer 输入发送 | Skill 卡片直达 |
| --- | --- | --- |
| `text` | 用户输入或零宽文本 | Skill 使用文案 |
| `attachments` | 普通附件 + 槽位附件 | 空数组 |
| `hook` | 当前 Composer 选中的 Hook/Skill | 由 Skill 构造 |
| `richTextHtml` | 输入富文本转换 | Skill mention + 使用文案 |
| `analyticsContext` | 通常为空 | Skill 直达归因 |

流程：

```text
Skill Use Now
  → 检查登录、创建中、跳转中
  → handleCreateNewFlow()
  → saveHomeAgentHandoff()
  → navigate("/canvas/{flowId}")
```

---

## 九、这些字段不能混

| 字段 | 属于 | 不能当成 |
| --- | --- | --- |
| `composerText` | 首页输入框 | 画布项目标题 |
| `composerRichTextHtml` | 首页富文本 mention | 后端可靠消息 |
| `remoteUrl` | 附件上传结果 | 浏览器 File |
| `librarySaveFailed` | 素材库入库失败 | 附件上传失败 |
| `assetSlotKind` | Agent 附件上下文 | 素材库 id |
| `flow_id` | flow project | Agent run id |
| `home-agent-handoff` | 当前标签页临时交接 | 服务端任务队列 |
| `flow_task_id` | workflow run 执行任务 | 首页创建的 flow id |
| `hook` | 首轮 Agent 输入配置 | 已执行的 workflow |

判断首页 Composer 链路是否完成，看的是：附件远端 URL 准备好、语义槽位可选入库、空 flow 创建成功、handoff 写入并跳转、画布当前 `flowId` 的 Agent 首轮消息被 accepted。不是只看页面能跳到 `/canvas/{flowId}`。
