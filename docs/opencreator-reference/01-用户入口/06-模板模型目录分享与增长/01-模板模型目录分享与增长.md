# OpenCreator 是怎么做模板、模型目录、分享与增长的

## 一、先说结论

这组能力到“页面能渲染、用户能选中、链接能打开”就结束。模型执行在用户另外点击 Run 之后。

```text
模板市场
  → 只读 status=published
  → 预览走分享快照
  → 复制才 POST /api/v2/flow/project

模型下拉
  → /models/list + /dropdown-order
  → 选中 model_id

作者分享
  → POST /api/v3/share 写下快照
  → 访客先 GET /info
  → 需要白名单再 POST /visit

邀请
  → 本地记住 invite
  → 注册写入 Clerk metadata
  → webhook 发注册积分
  → 7 天内付费再发一笔
```

必须分开的是：

- 模板列表：公开目录，不包含别人的草稿。
- 分享快照：创建那一刻的 nodes / edges。
- 自己的 flow project：复制或打开编辑页之后的图。
- 模型目录：名称、价格、排序。
- AI registry：任务真正能调用的模型。
- 邀请积分：注册和付费两条入账。
- B2B 弹窗：旁路通知，不改支付和 run。

规则细节在 [00-模板模型目录分享与增长技术点.md](./00-模板模型目录分享与增长技术点.md)。这篇按文件讲谁调用谁。

## 四、运行时链路

### 1. 打开模板市场

```text
/skills?tab=workflow
  → AgentSkillsPage
  → useTemplatesInfiniteQuery
  → GET /api/v1/templates/page
  → GET /api/v1/templates/categories/list
  → TemplateDao 只查 published
```

首页横滑轨走 `homeCategory`，每个分类 5 条。导航可以提前 prefetch。

### 2. 预览并复制

```text
卡片 origin_flow_id + share_id
  → /canvas/view/{flowId}?shareid=
  → getShareInfoV3
  → 只读渲染快照

用户点 Use
  → 未登录则先登录
  → getShareInfoV3
  → postSaveFlow
  → /canvas/{newFlowId}?from_template=1
```

只读画布上的 Copy 不再读模板接口，直接把 store 里的图 `postSaveFlow`。

编辑画布里的模板弹窗、模板工具和 Creator Skills 走 `cloneTemplateToFlow(share_url)`，调用 `POST /api/v2/share/visit`，把节点追加进当前图。

### 3. 模型下拉

```text
ClientProviders
  → useCloudModelDataQuery
  → GET /api/v1/models/list?config_name=all
  → useModelDropdownOrderQuery
  → GET /api/v1/models/dropdown-order?group=all
  → useEnrichedModelsData
  → ModelSeletion
```

内部 upsert 之后，下一次 5 分钟刷新或重新进页面才会看到新价格和排序。

### 4. 作者创建分享

```text
SharePanel
  → generateFlowShareLink
  → POST /api/v3/share
  → FlowService.get_workflow_project(flow_id, user_id)
  → ShareFlowDao.create_share_flow
  → /canvas/view/{flow_id}?shareid={share_id}
```

### 5. 访客打开链接

```text
/canvas/?shareid=
  → info
  → 已登录则 visit
  → owner 去编辑页，其他人去 /canvas/view

/canvas/view/{flowId}?shareid=
  → info
  → need_auth 则停在登录
  → 否则把快照写入只读 store
```

已登录用户直接打开带 `shareid` 的编辑路由时，`useOneFlow` visit。App 类型再读 `GET /api/v3/app-flow/{flow_id}`。

### 6. 邀请

```text
/?invite={code}
  → InviteCodeTracker
  → localStorage
  → 注册 body.invite_code
  → Clerk unsafe_metadata.inviteCode
  → user.created
  → process_registered_invite
  → 200 积分，最多 10 人

被邀请人付费
  → process_paid_invite_reward
  → 7 天内再给邀请人 1000 积分
```

Share & Earn 只读 `invite_summary` 和两份明细。Discord 和 Affiliate 离开本站。

### 7. Agent 目录

```text
首页导演种子 / viral hooks / 角色选择
  → GET /api/v3/agent-catalog/hooks 或 /roles
  → 只返回 published
  → 选中项成为后续 Agent 输入
```

### 8. B2B 弹窗

```text
支付成功、v1 create_flow_task、Consumer run_flow 或扣费
  → emit_b2b_signal_event
  → 规则写出 pending action
  → 登录后 GET pending-upgrade-popup
  → 打开订阅弹窗
  → POST actions/{id}/shown
```

周期任务另送到期飞书。这步不改订单状态，也不取消 run。

## 五、和 NovelComic 对照

NovelComic 按 OpenCreator 这组目录来搬时，先有登录、flow project 保存和积分入账。顺序是：

1. 先做 published 模板的分页、分类和首页分类轨。
2. 再做模型目录的公开读、内部写入和节点下拉。
3. 再做 V3 分享快照，以及画布克隆用的 `POST /api/v2/share/visit`。
4. 模板预览、另存新项目、克隆进当前画布，都接在分享快照之后。
5. 邀请码从 URL 到 webhook 入账，再做 Share & Earn。
6. Agent Catalog 只做公开读。
7. 最后接 B2B。事件发失败不能挡住支付和 run。

市场能列出模板，还不表示复制已成功。复制成功的标志是新的 `flow_id`。下拉里看见 `model_id`，还不表示 registry 能执行它。分享页能看见节点，还不表示这次访问创建了 workflow run。
