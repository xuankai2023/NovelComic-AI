## 外层包

HTTP 成功响应外面仍是统一包：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

`POST /api/v2/flow/runs`、`continue`、`cancel` 成功时 HTTP 状态码是 `202 Accepted`，但响应体仍按统一包返回，`data` 里放 run command response。

前端 `flow.ts` / `results.ts` 读的是 `data`。

## 一、编辑画布项目读取

### `GET /api/v2/flow/project/{flow_id}`

用途：打开编辑画布时读取用户正在编辑的 flow project。

认证：必须带 `Authorization: Bearer <__opencreator_jwt>`。

后端当前用户来源：

```text
get_authenticated_user()
  → AuthUser.user_id
```

路径参数：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `flow_id` | string | 必填。当前项目 id |

成功时 `data` 最小形状：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `flow_id` | string | 项目 id |
| `nodes` | array | React Flow 节点 |
| `edges` | array | React Flow 边 |
| `details` | object | 项目详情 |
| `created_at` | string 或空 | 创建时间 |
| `updated_at` | string 或空 | 更新时间 |
| `time_zone` | string | 项目时区，可为空 |
| `allow_reshare` | boolean | 是否允许再分享，缺省按 OpenCreator 用 `true` |
| `parent_flow_id` | string 或空 | 父项目 / 模板来源 |
| `last_view_time` | string 或空 | 最近查看时间，后端可更新 |

`details` 最小形状：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `flow_id` | string 或空 | 详情所属项目 id，兼容 OpenCreator 后端实体 |
| `project_name` | string | 画布标题 |
| `created_at` | string 或空 | 详情创建时间 |
| `updated_at` | string 或空 | 详情更新时间 |
| `time_zone` | string 或空 | 详情时区 |
| `snapshot` | object 或空 | 截图信息 |
| `app_mode_config` | object 或空 | App 模式配置 |

`snapshot`：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `snapshot_url` | string | 预览图地址 |
| `snapshot_thumbnail_url` | string | 缩略图地址 |

示例：

```json
{
  "flow_id": "flow_xxx",
  "details": {
    "flow_id": "flow_xxx",
    "project_name": "Untitled",
    "created_at": "2026-09-26T08:00:00Z",
    "updated_at": "2026-09-26T08:10:00Z",
    "time_zone": "Asia/Shanghai",
    "snapshot": {
      "snapshot_url": "",
      "snapshot_thumbnail_url": ""
    },
    "app_mode_config": null
  },
  "nodes": [],
  "edges": [],
  "allow_reshare": true,
  "parent_flow_id": null,
  "created_at": "2026-09-26T08:00:00Z",
  "updated_at": "2026-09-26T08:10:00Z",
  "time_zone": "Asia/Shanghai",
  "last_view_time": "2026-09-26T08:11:00Z"
}
```

失败语义：

| 场景 | 结果 |
| --- | --- |
| 没带 JWT / JWT 无效 | 401 |
| `flow_id` 不存在 | not found |
| `flow_id` 存在但不属于当前用户 | 按无权限或 not found 处理，不返回别人的项目 |

## 二、历史节点结果补拉

### `POST /api/v3/result/all_batch_fetch`

用途：打开画布后补拉已有节点结果快照。不是创建 run，不触发模型。

认证：必须带 `Authorization: Bearer <__opencreator_jwt>`。

请求体：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `workflow_id` | string | 必填。就是当前 `flow_id` |
| `node_ids` | string[] | 必填。要查询结果的节点 id |
| `share_id` | string 或空 | 分享查看场景可选 |

示例：

```json
{
  "workflow_id": "flow_xxx",
  "node_ids": ["node_a", "node_b"]
}
```

成功时 `data` 形状：

```json
{
  "node_a": [
    {
      "run_id": "run_xxx",
      "node_id": "node_a",
      "outputs": []
    }
  ],
  "node_b": []
}
```

约束：

- key 是 `node_id`。
- value 是该节点的结果数组。
- v3 语义是每个节点只取最新结果。
- 没有结果时返回空数组，不是错误。
- 后端要用当前登录用户写入 `request.user_id`，不能信前端传 `user_id`。

## 三、创建 workflow run

### `POST /api/v2/flow/runs`

用途：用户点击 Run 后创建一次执行实例。

认证：必须带 `Authorization: Bearer <__opencreator_jwt>`。

请求模型：`CreateWorkflowRunRequest`。

字段：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `client_request_id` | string | 必填，1 到 128 字符。前端生成，用于幂等 |
| `command_id` | string 或空 | 可选，1 到 128 字符 |
| `flow_id` | string 或空 | 当前项目 id |
| `flow_task` | object | 必填。当前要执行的图 |
| `start_ids` | string[] | 默认空数组 |
| `end_ids` | string[] | 默认空数组 |
| `user_selection` | any | 默认空对象，HITL 选择 |
| `locale` | string 或空 | 语言环境 |
| `run_mode` | string | `global` / `selected_nodes` / `single_node`，默认 `global` |
| `intent_node_ids` | string[] | 默认空数组 |

示例：

```json
{
  "client_request_id": "cmd_123",
  "flow_id": "flow_xxx",
  "flow_task": {
    "nodes": [],
    "edges": []
  },
  "start_ids": [],
  "end_ids": [],
  "user_selection": {},
  "locale": "zh-CN",
  "run_mode": "global",
  "intent_node_ids": []
}
```

成功时 HTTP 状态：

```text
202 Accepted
```

成功时 `data` 形状：`WorkflowRunResponse`。

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `flow_task_id` | string | 这次执行任务 id，WebSocket 用它连接 |
| `flow_run_id` | string | 逻辑 run id |
| `trace_id` | string | 链路追踪 id |
| `status` | string | run 当前状态 |
| `idempotent_replay` | boolean | 是否幂等重放 |
| `flow_task` | object 或空 | 快照，可选 |
| `flow_run_state` | object 或空 | run 状态，可选 |
| `flow_node_state` | array | 节点状态数组 |
| `snapshot_cursor` | string 或空 | 快照 cursor |
| `last_event_id` | string 或空 | 最后事件 id |

示例：

```json
{
  "flow_task_id": "task_xxx",
  "flow_run_id": "run_xxx",
  "trace_id": "trace_xxx",
  "status": "accepted",
  "idempotent_replay": false,
  "flow_task": null,
  "flow_run_state": null,
  "flow_node_state": [],
  "snapshot_cursor": null,
  "last_event_id": null
}
```

注意：`202` 只表示命令受理，不表示节点完成。

## 四、继续 workflow run

### `POST /api/v2/flow/runs/{flow_task_id}/continue`

用途：HITL 节点暂停后，用户做选择，再继续同一次 run。

路径参数：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `flow_task_id` | string | 必填。创建 run 时返回 |

请求模型：`ContinueWorkflowRunRequest`。

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `command_id` | string | 必填，1 到 128 字符 |
| `flow_run_id` | string | 必填 |
| `flow_task` | object | 必填 |
| `start_ids` | string[] | 必填 |
| `user_selection` | any | 默认空对象 |
| `locale` | string 或空 | 语言环境 |

成功时同样返回 `202 Accepted` 和 `WorkflowRunResponse`。

## 五、取消 workflow run

### `POST /api/v2/flow/runs/{flow_task_id}/cancel`

用途：停止正在运行的 workflow run。

路径参数：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `flow_task_id` | string | 必填 |

请求模型：`CancelWorkflowRunRequest`。

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `command_id` | string | 必填，1 到 128 字符 |

示例：

```json
{
  "command_id": "cancel_123"
}
```

成功时返回 `202 Accepted` 和 `WorkflowRunResponse`。

关闭 WebSocket 不是取消。取消必须调这条接口。

## 八、workflow run 事件 WebSocket

### `WS /api/v2/flow/runs/{flow_task_id}/events/{connection_id}`

用途：接收某次 run 的可恢复事件流。

路径参数：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `flow_task_id` | string | 必填。创建 run 时返回 |
| `connection_id` | string | 必填。前端每次物理连接生成 |

打开连接后第一条消息必须是认证：

```json
{
  "event_type": "auth",
  "protocol_version": 2,
  "token": "<__opencreator_jwt>"
}
```

认证成功后服务端返回：

```json
{
  "event_type": "authenticated",
  "flow_task_id": "task_xxx",
  "connection_id": "conn_xxx",
  "trace_id": "trace_xxx"
}
```

然后前端发送 attach：

```json
{
  "event_type": "attach_flow",
  "protocol_version": 2,
  "flow_task_id": "task_xxx",
  "connection_id": "conn_xxx",
  "last_event_cursor": null
}
```

恢复连接时，`last_event_cursor` 带上本地保存的 cursor：

```json
{
  "event_type": "attach_flow",
  "protocol_version": 2,
  "flow_task_id": "task_xxx",
  "connection_id": "conn_yyy",
  "last_event_cursor": "1700000000-0"
}
```

常见服务端事件：

| `event_type` | 用途 |
| --- | --- |
| `resume_ready` | 恢复连接准备完成 |
| `resume_error` | 恢复失败 |
| `flow_snapshot` | run 快照 |
| `start_flow` | run 开始 |
| `node_status` | 节点状态变化 |
| `workflow_error` | 工作流错误 |
| `flow_killed` | run 被停止 |
| `pong` | 心跳响应 |

每条回放事件会带：

| 字段 | 用途 |
| --- | --- |
| `event_cursor` | 事件 cursor，用于下次恢复 |
| `replayed` | 是否回放事件 |

认证失败时关闭连接，常见 code：

| 场景 | 行为 |
| --- | --- |
| 第一条不是 `auth` | 返回 `resume_error`，关闭 4401 |
| token 无效或过期 | 返回 `AUTH_FAILED`，关闭 4401 |
| run 不存在或不属于当前用户 | 返回 `RUN_NOT_FOUND`，关闭 4404 |

## 九、分享画布读取

分享页不是编辑页。入口：

```text
/canvas/view/{flowId}?shareid=...
```

前端会调用分享接口读取分享信息。现有总览里只需要记住返回关键字段：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `need_auth` | boolean | 是否需要登录后才能看 |
| `flow` | object 或空 | 分享里的 nodes / edges |
| `flow_is_me` | boolean | 当前用户是否 owner |
| `share_type` | string | 分享类型 |
| `allow_reshare` | boolean | 是否允许再分享 |
| `project_name` | string | 展示标题 |
| `app_mode_config` | object 或空 | App 模式配置 |

`need_auth = true` 时，前端打开登录弹窗；登录完成后刷新页面重新取分享信息。

---

## 十、这些字段不能混

| 字段 | 属于 | 不能当成 |
| --- | --- | --- |
| `flow_id` | 项目定义 | run id |
| `flow_task_id` | 一次执行任务 | 项目 id |
| `flow_run_id` | 逻辑运行实例 | WebSocket 连接 id |
| `connection_id` | 一次物理 WebSocket 连接 | 用户 id |
| `event_cursor` | 事件流恢复位置 | 节点结果 id |
| `workflow_id` | 结果接口里的项目 id | 执行状态 |
| `node_id` | 节点 id | 模型结果本身 |

判断画布是否“加载完成”，看的是项目数据和初始结果；判断模型是否“正在跑”，看的是 workflow run 和 WebSocket 事件。
