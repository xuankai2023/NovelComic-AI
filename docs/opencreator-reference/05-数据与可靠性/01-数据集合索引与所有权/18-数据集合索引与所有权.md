# 18：数据集合、索引与所有权

## 职责

- `opencreator-frontend` 只保存短期浏览器状态，不是 Mongo 事实 Owner。
- `opencreator-publisher` 拥有用户、项目、命令、Developer API、支付等入口事实，并创建相应索引。
- `opencreator-consumer` 拥有工作流运行态、节点态、模型调用、Inbox/Outbox 与恢复索引。
- `opencreator-ai` 拥有 `ai_task`、attempt、provider event、callback delivery 等 AI 网关事实。
- `opencreator-agent` 拥有 Agent session/message/event/tool trace；同时只读或受控读写部分共享 workflow、billing 集合。

## 入口

- Publisher 启动时执行 `ensure_*_indexes`。
- Consumer Mongo 连通检查同时执行 `init_consumer_v1_indexes`，四个 v2 必需索引失败会阻止启动。
- AI worker 启动时执行 `ensureMongoIndexes`。
- Agent 启动时执行 `ensure_indexes`，共享集合的索引冲突 85/86 被降为 warning。
- Frontend 的 `sessionStorage/localStorage` 入口包括 command journal、WebSocket cursor 和本地副作用 claim。

## 主链

```text
Publisher 接收命令
  → flow_task / workflow_command
  → Consumer flow_command_inbox
  → flow_run_state / flow_node_state / model_invocation
  → AI ai_task / attempt / provider_event / callback_delivery
  → Consumer results / usage_v2 / flow_event_outbox
  → Publisher Event Store → Frontend cursor
```

集合共享不等于所有权共享：Publisher 可读取运行快照，Agent 可读取 workflow 与结果，但运行状态迁移仍由 Consumer 负责；AI 的 `media_face_verifications` 可配置到共享库，也不因此获得用户项目所有权。

## 关键状态/消息

- 唯一索引保护逻辑身份：`workflow_command(user_id, command_id)`、Inbox `command_id`、Outbox `event_id`、AI `ai_task_id`、AI `(provider, provider_request_id, event_id)`。
- 查询索引保护恢复扫描：Outbox `(status, next_attempt_at)`、Inbox `(status, lease_expires_at)`、invocation `(status, updated_at)`。
- TTL 只做终态保留期：命令/Outbox 必须先写 `expires_at` 才会清理；TTL 不是业务完成信号。
- 租户过滤通常是 `user_id` 与资源 ID 的复合查询/索引；只有资源 ID 而没有 Owner 条件不能证明隔离。
- Frontend command journal 的 ID、Event Store cursor、浏览器副作用 claim 是三种不同身份，不能互相替代。

## 跨仓边界

- Publisher 是入口与用户资源 Owner；Consumer 是执行状态机 Owner；AI 是厂商任务 Owner；Agent 是会话 Owner；Frontend 仅持客户端缓存。
- 共享 Mongo 只是部署事实，不授权任一仓任意改写别仓状态机。
- 同名集合由多仓创建索引时必须保持键序和选项兼容；索引名不同也可能触发 85/86。
- `media_face_verifications` 是 Publisher 与 AI 的受控共享集合，协议定位键为媒体 URL 与 BytePlus asset ID；它不是所有集合都可跨仓直写的先例。

## 遗留/未启用

- Agent 对共享集合的 85/86 一律 warning，能启动但可能掩盖真正不等价的索引规格，需要部署侧核验。
- Consumer 的必需 v2 索引仅对 Inbox/Outbox 四项 fail-fast，其余创建失败只告警。
- Atlas Search/Vector Search 索引由 Agent 检查并尝试补过滤字段；索引不存在时仅 warning。
- 浏览器存储是 best-effort，隐私模式或清理后会丢；不能当服务端幂等事实。
- 现码仍有多仓直连共享 Mongo，尚未形成严格的“每仓独库 + API 所有权”隔离。
