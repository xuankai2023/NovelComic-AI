## 1. Publisher 白名单

OpenCreator 对照：[auth_middleware.py](../../../../../opencreate/opencreator-publisher/middleware/auth_middleware.py)、[api_key.py](../../../../../opencreate/opencreator-publisher/dependencies/api_key.py)、[core/register.py](../../../../../opencreate/opencreator-publisher/core/register.py)。

NovelComic 落在 `novelcomic-publisher/app/middleware/auth_middleware.py`。`WHITE_LIST` 保持现在这些公开路径：健康检查、文档、发码登录、`/api/v2/cos/*`、`/api/v1/models/*`、catalog、internal model-config、用户创建、支付 webhook、社交 webhook、飞书。

```text
业务 HTTP
  → 路径不在 WHITE_LIST
  → 验 JWT
  → request.user.user_id = sub
```

v1 `flow_task` WebSocket、SQS `subscribe_receive_message`、`main_developer.py` 的第二套 `start_mq_consumer`，留在 OpenCreator 对照里。Miniapp 的 TODO 到 `completed` 也留在对照里，见 [miniapp.py](../../../../../opencreate/opencreator-publisher/tasks/miniapp.py)。

做完：`/api/v1/flow/flow_task/{ws_id}` 打到 NovelComic 时走 JWT 失败，而不是 `PUBLIC_USER`。启动路径里的结果消费者是主进程那一个。

## 2. Consumer 回调和恢复查询

OpenCreator 对照：[main.py](../../../../../opencreate/opencreator-consumer/main.py)、[s3.py](../../../../../opencreate/opencreator-consumer/utils/s3.py)、[flow_recovery_service.py](../../../../../opencreate/opencreator-consumer/services/workflow/flow_recovery_service.py)。

NovelComic 落在 `novelcomic-consumer/app/main.py`：

```text
consumer_webhook_secret 为空
  → _verify_callback_signature 返回 True

有密钥
  → 校验时间戳
  → HMAC-SHA256
  → compare_digest
```

配置说明写成：密钥为空则跳过验签；配了密钥才核对 `x-oc-timestamp` 和 `x-oc-signature`。

终态补 outbox 的查询保持 `protocol_version == 2`。缩略图函数和 SQS `a_send_message` 不接进 `register_init`。

做完：空密钥的回调返回验签通过；配上密钥后，错误签名进不了 finalize。恢复任务的终态查询带 `protocol_version == 2`。

## 3. AI 开关和注册表

OpenCreator 对照：[load-config.ts](../../../../../opencreate/opencreator-ai/packages/config/src/load-config.ts)、[models/index.ts](../../../../../opencreate/opencreator-ai/packages/core/src/models/index.ts)、[provider-webhooks.ts](../../../../../opencreate/opencreator-ai/apps/api/src/routes/provider-webhooks.ts)。

NovelComic 的模型列表只收已经写进注册表的类。Youchuan 视频两个类在 OpenCreator 里保持注释，就留在注释里。

```text
ENABLE_BULL_BOARD、CONFIG_LOADER_ENABLED、ALERT_FEISHU_ENABLED、MODEL_CALL_FEISHU_ENABLED
  → 未设置时为 false

provider == tencent
  → verifyTencentWebhookSignature

  → COS 五项齐全则为 cos
  → 否则为 pass_through
```

`assertTaskStatusCanAdvance` 在有 worker import 之前，状态约束写在那个 worker 的写路径上。

做完：未设置上述四个变量时，Bull Board 路由不存在。注册表里能找到 V8.1 / V8.2，找不到两个被注释的 Youchuan 视频类。

## 4. Agent 的 410 和 MCP

OpenCreator 对照：[server.py](../../../../../opencreate/opencreator-agent/creato/api/server.py)、[loop.py](../../../../../opencreate/opencreator-agent/creato/core/loop.py)、[event_bridge.py](../../../../../opencreate/opencreator-agent/creato/workflow/event_bridge.py)。

NovelComic 落在：

| 文件 | 行为 |
| --- | --- |
| `novelcomic-agent/src/novelcomic_agent/api/server.py` | `POST /v1/agent/chat` 返回 410，`code` 为 `USE_AGENT_RUNS` |
| `novelcomic-agent/src/novelcomic_agent/core/loop.py` | `_connect_mcp` 第一行 `return` |

OpenCreator 的 chat 在 410 之前还会鉴权，`raise` 后面留着旧实现。NovelComic 保持现在这个短函数。`POST /api/v1/agent/chat/stop` 若要补，同样返回 410，并指向 runs 的 cancel。

```text
SSE 窗口过期 → code = RESUME_WINDOW_EXPIRED
旧 chat       → code = USE_AGENT_RUNS
```

`RunSnapshot` 在补上 `user_id` 之前，`workflow/select` 与 `generation/confirm` 分开写。确认接口比对 `pending.user_id`。mem0 在 `MemoryConfig.enabled` 为真时才连接。主 profile 沿用 OpenCreator 的注释，不注册 `ContinueWorkflowTool`。

做完：`POST /v1/agent/chat` 的响应是 410。一次 run 的工具列表里没有动态 MCP 工具。

## 6. 再改 OpenCreator 对照源

前五节核对完以后，删除兼容入口按这个顺序：

1. 写下标签、调用方和删除条件。
2. 给 v1 flow、旧 Agent chat、legacy model id 加上调用量。
3. 停止写入旧格式，改读路径，去掉 fallback，最后删路由或集合。
4. 未启用能力留着显式开关，在不含密钥的 config dump 里写出开或关。
5. 跨仓删除用同一份 revision manifest 跑过生产方和消费方。位置见 [测试脚本与架构治理](../04-测试脚本与架构治理/02.文件编写顺序.md)。

[dao/payments.py](../../../../../opencreate/opencreator-publisher/dao/payments.py) 的 `deprecated` 方法在调用方还在时保持原函数。

## 完整验收顺序

1. 任选一条入口，能在 00 的表里找到标签，并在 01 里指出停住的那一行。
2. `CLI_AUTH_ENABLED=false` 时，CLI 入口返回 404，`detail` 为 `CLI authentication is disabled`。
3. Publisher 启动调用 `start_mq_consumer` 和 `start_workflow_v2_mq_consumer`。SQS `subscribe_receive_message` 保持注释。
4. Miniapp 任务状态会写成 `completed`，执行体仍是 TODO。
5. 缩略图函数返回 `None`。Consumer 在密钥为空时验签函数返回 `True`。
6. 四个 AI 布尔开关未设置时为关。腾讯 webhook 调用 `verifyTencentWebhookSignature`。
7. `POST /v1/agent/chat` 返回 410，`code` 为 `USE_AGENT_RUNS`。`_connect_mcp` 第一行返回。
8. `workflow/select` 按 `flow_task_id` 取快照。`generation/confirm` 比对 `pending.user_id`。
9. `/home` 重定向到 `/`。`/pricing-test` 没有路由文件。
10. Frontend README 的目录与 `src/routes` 一致时，文档债这一行可以划掉。Publisher 的路由清单以 `controller/` 为准。
