# 遗留兼容未启用与文档债：这里面有哪些技术点

这一组给五仓里已经存在的入口贴标签。画布主链仍是 v2 project、v2 run 和可恢复 WebSocket。文件怎么走，看 [01](./01-遗留兼容未启用与文档债.md)；先核对哪份，看 [02](./02.文件编写顺序.md)。

先背一句话：

```text
文件在，先看有没有注册；
注册了，再看函数第一行；
README 单独对现码。
```

| 标签 | 现码满足什么 |
| --- | --- |
| 主链 | 当前产品在调用，状态和恢复语义是完整的 |
| 兼容 | 旧客户端、旧数据或滚动发布还用得到，路由或函数仍会执行 |
| 旁路 | 在运行，服务对象在画布 v2 run 之外 |
| 未启用 | 文件或路由在仓里，运行时被 410、注释、默认关闭的开关挡住 |
| 文档债 | 注释、README 或旧文档和现码对不上 |

能把运行标签写成未启用的，是这三类：处理函数返回 410、注册行被注释或没进注册表、开关默认关闭并且运行时读取这个开关。`deprecated` 只说明作者标过旧，函数仍可能被调用。
