# [ANM-007] 自动关键帧

> 实施日期：2026-10-06

## 1. 本轮目标

- 当前状态：ANM-002 已有属性秒表与 Viewer Position 关键帧写入，但没有独立 Auto-Key 状态，已动画图层在关闭自动记录的语义下仍可能静默产生关键帧。
- 目标状态：Auto-Key 默认关闭且状态清晰；开启后 Viewer 和 Position Inspector 在当前局部帧新增或更新关键帧；关闭后未动画属性修改整段，已动画属性阻止直接写入并提示修复动作。
- 本轮只做：图像图层 Position；Auto-Key 模式、持久化、Timeline 主入口、Viewer 拖拽、Position Inspector、Undo/Redo 与边界提示。
- 本轮不做：Graph Editor、多关键帧选择、效果属性、父子级和非图像图层动画模型。

## 2. AE 位置契约

- 主要参照：After Effects Timeline Toolbar / Auto-keyframe mode。
- 顶部菜单路径：无。
- 工具栏位置：底部 Timeline 顶栏，位于当前帧和帧率之后、搜索之前。
- 面板归属：Timeline 为主入口；Position Inspector 是同一状态的辅助编辑入口。
- 时间线位置：宽屏显示固定尺寸的“状态灯 + 自动关键帧”控件；开启时状态灯及边框转为红色录制态，窄屏仅保留带 tooltip 的状态灯按钮。
- Viewer 表现：拖动已选图像时，开启 Auto-Key 写入当前局部帧 Position；关闭时仅允许未动画 Position 修改整段。
- 提交方式：拖动过程仅更新预览，Pointer Up 合并为一次 Undo；数值编辑沿用 NumberControl 的提交边界。
- 取消与失败：越出 Item 时间范围或关闭 Auto-Key 后编辑已有动画属性时不写状态，并给出明确 Toast。

## 3. 状态与命令

- 编辑器模式 owner：`EditorState.autoKeyEnabled`，不是 ProjectDocument 内容，不进入 Undo 栈。
- 默认值：`false`；用户显式切换后通过独立偏好键恢复，旧工程和旧会话没有该字段时仍为关闭。
- 动画 owner：继续使用 `ImageItem.motion.transform`，没有新增第二套关键帧数据。
- 统一判定：`resolveAutoKeyTransformWrite` 处理静态写入、当前帧关键帧写入、已动画属性阻断和 Item 边界校验。
- 求值：写入值来自 `evaluateTransformAtFrame`，预览和最终渲染继续共享现有 evaluator。

## 4. 写入规则

| Auto-Key | Position 动画状态 | 结果                                                 |
| -------- | ----------------- | ---------------------------------------------------- |
| 关       | 未动画            | 修改静态 Position，作用于整段                        |
| 关       | 已动画            | 阻止修改，提示开启 Auto-Key 或编辑时间线关键帧       |
| 开       | 未动画            | 当前局部帧创建第一个 Position 关键帧并开启该属性动画 |
| 开       | 已动画            | 当前局部帧新增或更新 Position 关键帧，不产生重复帧   |

## 5. 验收结果

- [x] Auto-Key 初始默认关闭。

- [x] 激活悬停态保持红色语义，键盘焦点有独立蓝色轮廓。
- [x] Viewer 拖拽和 Position Inspector 使用同一写入规则。
- [x] 当前帧按 Item 局部帧写入，越界不创建关键帧。

- [x] 连续 Viewer 拖拽仅提交一次 Undo。
