# 动态漫画 AE 类功能人工校验步骤

> 适用工程：`novelcomic-remotion`  
> 用途：验证当前工程中面向动态漫画的 AE 类能力是否能从素材进入工程、完成动画编排、生成对白字幕、预览、分批渲染和交付。  
> 校验方式：只记录需要人工操作、播放、逐帧观察、刷新重载、下载或对比最终画面的内容。数据模型、纯函数、API 契约、源码静态检查和已有自动化测试不在本清单重复验证。

## 0. 范围说明

### 0.1 本文档覆盖的功能

本清单覆盖当前工程已经具备或对动态漫画生产有明确入口的 AE 类能力：

- 动态漫画工程和画布初始化。
- 多轨道、多 item 时间线。
- 图片、视频、音频、文字、字幕、GIF 和色块图层。
- 图层的起止时间、位置、尺寸、旋转、透明度、裁切和淡入淡出。
- 图层隐藏、静音、复制、粘贴、拖拽、裁切、扩展、滚动剪辑和时间线缩放。
- Shot 创建、编辑、删除、排序、时长和转场。
- LayerPackage 图层包导入、图层语义、图层顺序和 L0 恢复。
- 2D 关键帧：位置、缩放、旋转和透明度。
- 缓动、循环、往返循环和锚点。
- 图层 motion 与 Shot camera motion 叠加。
- `breathing`、`float`、`hair-sway` 等图层预设。
- `camera-push`、`camera-pull`、`pan-left`、`pan-right` 等镜头预设。
- 眼睛眨眼和嘴型 sprite 状态切换。
- 对白、字幕、配音、音频淡入淡出。
- Clean Plate、Cutout、重组、透明洞和运动暴露区域检查。
- 首帧、中间帧、末帧、Player、静帧和最终视频核对。
- 5～18 秒批次规划、批次渲染、批次重试和交付清单。

### 0.2 当前不适用的真实 AE 功能

以下功能当前工程没有实现，不纳入“通过/失败”统计，统一标记为 `不适用`：

- `.aep` 工程导入和导出。
- AE 表达式和表达式控制器。
- Graph Editor 曲线编辑器。
- 逐属性的 AE 式时间轴关键帧编辑器。
- 父子级 Parenting 和自动继承父级变换。
- Pre-compose 或 Nested Composition 的完整产品化能力。
- AE Mask、Shape Path、Track Matte 和遮罩动画。
- Blend Mode 混合模式。
- 3D Layer、3D Camera、Light、景深和透视空间。
- 贝塞尔空间运动路径、Auto-Orient 和 Puppet Pin。
- 骨骼绑定、网格变形、Live2D 和粒子系统。
- PSD/AE 文件直接导入。

如果产品范围后续增加上述能力，应新增独立校验章节，不能直接复用本文档的二维图层通过标准。

## 1. 校验准备

### 1.1 工具和素材

准备以下内容：

- 已启动的本地编辑器。
- `source.png`：单页原图。
- `source-with-hair-mouth.png`：包含可拆出头发、眼睛和嘴巴的原图。
- `background.png`：可用于背景图层测试的图片。
- 一组人物、背景、前景、头发、眼睛和嘴巴 PNG。
- 一段短旁白音频。
- 一段背景音乐。
- 至少两句对白文本。
- 一个包含多个 Shot 的 LayerPackage。

固定素材优先使用：

```text
tests/fixtures/comic-ps-loop/
```

### 1.2 建议测试工程

建议准备三个工程副本：

| 工程 | 用途 |
|---|---|
| `AE-BASE` | 时间线、图层、Shot 和基础变换 |
| `AE-COMIC` | LayerPackage、Clean Plate、sprite 和动态漫画 |
| `AE-DELIVERY` | 字幕、音频、批次、渲染和交付 |

每个工程开始前保留一个干净副本。发现失败时不要覆盖干净副本。

### 1.3 结果记录

每个功能记录以下结果之一：

- `通过`：操作完成，状态、画面和输出均符合预期。
- `失败`：可以操作，但结果错误或与预期不一致。
- `阻塞`：入口不存在、页面报错、资源无法加载或无法继续。
- `不适用`：当前版本没有该功能，且属于本文档明确排除项。

失败时记录：

1. 工程名称和素材名称。
2. 操作到第几步。
3. 预期结果和实际结果。
4. 截图、静帧、录屏或导出文件。
5. 刷新页面后是否仍然复现。

## 2. 工程初始化和画布

### 2.1 创建动态漫画工程

1. 打开动态漫画编辑页面。
2. 创建空白工程。
3. 设置竖屏画布，例如 `1080x1920`。
4. 确认帧率为 `30fps`。
5. 创建第一个 Shot。
6. 导入 `source.png`。
7. 将图片放入 Shot。
8. 保存工程。

**人工观察**

- 画布尺寸、帧率和工程总时长显示正确。
- 原图完整显示，没有拉伸、裁切、黑边或偏移。
- Shot 在时间线和分镜区域中的起止位置一致。
- Player、Canvas 和时间线没有初始化报错。
- 保存后刷新页面，工程仍然可以打开。

**通过标准**

- 工程可以被重新打开。
- 原图位置、尺寸和画面在刷新前后保持一致。
- 后续测试可从该工程复制出干净副本。

### 2.2 工程基础状态

1. 修改工程名称。
2. 修改 Shot 名称。
3. 修改工程时长或 Shot 时长。
4. 保存并刷新页面。

**人工观察**

- 工程名称和 Shot 名称在页面各处同步。
- 时长变化后，时间线、Player 和 Shot 边界同步。
- 工程没有出现空白末帧或多余内容。

## 3. 时间线和基础图层

### 3.1 多轨道和多种 item

依次添加以下内容：

1. 图片图层。
2. 视频图层。
3. 音频图层。
4. 文字图层。
5. 字幕图层。
6. GIF 图层。
7. 色块图层。

**人工观察**

- 每种 item 都能出现在正确轨道。
- 不同 item 的时间范围显示清楚。
- 播放时每种 item 都能在对应时间出现。
- 图层名称、缩略图和类型显示正确。
- 视频和 GIF 不会变成静止图片或空白。
- 音频图层在 Player 播放时能听到声音。

### 3.2 时间线移动和吸附

1. 拖动一个 item 到新的时间位置。
2. 将 item 拖到另一个 item 的边缘。
3. 开启或使用吸附。
4. 放大时间线。
5. 缩小时间线。
6. 播放拖动后的结果。

**人工观察**

- item 可以被准确拖动。
- 吸附位置清晰，不会突然跳到错误时间。
- 时间线缩放后 item 没有消失或改变时长。
- Canvas 和 Player 反映新的时间位置。

### 3.3 裁切、扩展和滚动剪辑

1. 缩短图片或视频 item 的起点。
2. 缩短 item 的终点。
3. 扩展 item 的起点或终点。
4. 对相邻 item 执行 rolling edit。
5. 播放修改前后的边界。

**人工观察**

- 裁切只影响时间范围，不错误改变素材内容。
- 扩展后的静态图片仍然持续显示。
- 视频或音频裁切后内部起点没有明显错乱。
- rolling edit 不会造成空档、重叠或对白错位。
- 撤销后能恢复修改前的时间线。

### 3.4 轨道隐藏和静音

1. 隐藏图片、视频或字幕轨道。
2. 恢复显示。
3. 静音音频轨道。
4. 恢复音频。

**人工观察**

- 隐藏轨道后 Canvas、Player 和静帧都不显示该轨道。
- 恢复显示后内容回到正确位置。
- 静音只影响声音，不影响画面。
- 保存重载后隐藏和静音状态保持一致。

## 4. 图层基础变换

### 4.1 位置、尺寸和旋转

对一个图片或拆层图像执行：

1. 修改水平位置。
2. 修改垂直位置。
3. 修改宽度和高度。
4. 等比缩放。
5. 修改旋转角度。
6. 在 Canvas 中直接拖动和缩放。

**人工观察**

- 数值面板和 Canvas 结果同步。
- 位置变化不会改变素材内容本身。
- 等比缩放不会产生异常拉伸。
- 旋转中心符合当前图层锚点。
- Canvas、Player 和静帧的几何结果一致。

### 4.2 透明度和淡入淡出

1. 将图层透明度设置为 `0`、`50%` 和 `100%`。
2. 添加淡入。
3. 添加淡出。
4. 播放淡入淡出区间。

**人工观察**

- `0%` 时图层不可见，`100%` 时完全显示。
- 淡入和淡出没有闪烁或突然跳变。
- 淡入淡出不影响其他图层的时间范围。
- 透明度和淡入淡出在最终视频中与 Player 一致。

### 4.3 裁切

1. 对图片或视频设置裁切区域。
2. 改变裁切范围。
3. 播放裁切后的结果。
4. 保存并刷新页面。

**人工观察**

- 裁切只影响可见区域。
- 裁切边界没有露出不应显示的内容。
- 刷新后裁切范围保持一致。

## 5. 图层复制、粘贴和编辑状态

1. 复制一个图片图层。
2. 粘贴到同一 Shot。
3. 将复制图层移动到其他时间。
4. 修改复制图层的名称、位置和透明度。
5. 删除复制图层。
6. 复制一个带 motion 的图层。

**人工观察**

- 复制图层拥有独立的时间和几何状态。
- 修改复制品不会联动原图层。
- 带 motion 的复制品不会丢失或错误引用动画。
- 删除复制品后没有残留画面、轨道或声音。

## 6. Shot 分镜系统

### 6.1 创建和编辑 Shot

1. 创建至少三个 Shot。
2. 给每个 Shot 设置不同名称。
3. 为每个 Shot 放入不同图片或图层。
4. 修改第二个 Shot 的起点或时长。
5. 删除一个 Shot。
6. 重新播放整个工程。

**人工观察**

- Shot 顺序与时间线顺序一致。
- 修改 Shot 时长后，后续 Shot 和相关内容同步移动。
- 删除 Shot 后，其图层和对白不会残留在错误位置。
- 每个 Shot 只显示属于自己的内容。
- 播放头跨 Shot 时不会出现错误画面或黑帧。

### 6.2 Shot 与图层、对白关联

1. 在不同 Shot 中分别添加图层。
2. 给每个 Shot 添加对白。
3. 移动或修改 Shot 边界。
4. 播放 Shot 边界前后。

**人工观察**

- 图层不会显示在错误 Shot。
- 对白不会跑到其他 Shot。
- Shot 边界修改后，图层和对白仍在正确时间内。
- 分镜面板、时间线和 Player 的 Shot 归属一致。

### 6.3 Shot 删除和恢复

1. 删除一个包含图层和对白的 Shot。
2. 撤销删除。
3. 重做删除。
4. 刷新页面。

**人工观察**

- 删除时相关图层、对白和转场一起处理。
- 撤销后 Shot、图层和对白完整恢复。
- 重做后删除结果再次成立。
- 刷新后不会出现孤立图层或孤立对白。

## 7. LayerPackage 导入和动态漫画图层

### 7.1 导入图层包

1. 打开 `AE-COMIC` 工程。
2. 导入包含 background、body、head、hair、eye 和 mouth 的 LayerPackage。
3. 选择目标 Shot。
4. 等待导入完成。
5. 查看图层面板和时间线。

**人工观察**

- 导入后每个图层出现在正确的 Shot。
- 图层语义、名称和顺序清楚。
- 人物、背景、前景、头发、眼睛和嘴巴的初始位置正确。
- 原图 L0 仍然可以恢复。
- 导入失败时不会破坏原工程。

### 7.2 图层顺序和遮挡

1. 分别隐藏背景、人物、头发和前景。
2. 调整两个图层的顺序。
3. 播放重组画面。

**人工观察**

- 图层顺序真实影响遮挡关系。
- 头发、手臂、前景和人物前后关系正确。
- 调整顺序后不会出现错误的透明区域。
- Shot 之间的图层顺序不会相互污染。

### 7.3 L0 恢复

1. 隐藏拆层结果。
2. 执行恢复 L0。
3. 关闭或隐藏 Cutout 和 Clean Plate。
4. 播放当前 Shot。
5. 再次恢复拆层显示。

**人工观察**

- L0 能恢复为原始画面。
- L0 恢复不会删除拆层资产。
- L0 和拆层显示模式之间可以切换。
- 切换后画面不会偏移或缩放改变。

## 8. Clean Plate、Cutout 和重组质量

### 8.1 Clean Plate

1. 选择头发或嘴巴 Cutout。
2. 生成 Clean Plate。
3. 在 Source、Layers 和 Normal 等预览模式之间切换。
4. 隐藏 L0。
5. 播放目标图层运动。

**人工观察**

- Clean Plate 覆盖被拆出区域，没有误伤周围画面。
- Clean Plate 与原图画布覆盖关系正确。
- 隐藏 L0 后背景仍完整。
- Clean Plate 失败时 L0 仍可见，原图没有被破坏。
- Normal 模式不依赖 L0 掩盖问题。

### 8.2 Cutout 初始对齐

1. 只显示原图和 Cutout。
2. 隐藏原图，只显示 Cutout。
3. 切换回 Normal。
4. 将 Cutout 移动 `10 px`。
5. 撤销移动。

**人工观察**

- Cutout 初始位置与原图中的目标位置一致。
- Cutout 边界没有明显黑边、白边或错误裁切。
- 移动后原位置没有残影或透明洞。
- 撤销后画面恢复到原始重组状态。

### 8.3 质量预览和运动暴露

1. 打开 overlay、difference 或质量预览。
2. 查看 Source、Layers、Normal 和差异结果。
3. 将头发、嘴巴或人物移动到容易暴露背景的位置。
4. 查看透明洞、残影和边缘诊断。

**人工观察**

- 预览模式切换后显示的是当前模式结果。
- Overlay 能帮助定位对齐问题。
- Difference 与实际画面差异位置一致。
- 运动暴露区域能被明确提示。
- 质量问题不会被错误标记为通过。

## 9. 关键帧动画

### 9.1 位置关键帧

1. 选择一个图片或 Cutout 图层。
2. 设置起始位置。
3. 在后续帧设置另一个位置。
4. 播放关键帧之间的区间。
5. 拖动播放头逐帧查看。

**人工观察**

- 起始帧和结束帧位置正确。
- 中间帧有连续运动。
- 没有突然跳回起始位置。
- 关键帧前后的图层显示正常。

### 9.2 缩放关键帧

1. 在首帧设置 `scale = 1`。
2. 在中间或末帧设置放大。
3. 再添加缩小关键帧。
4. 播放整个区间。

**人工观察**

- 缩放以正确锚点进行。
- 图层不会突然改变位置。
- 缩放期间边缘没有异常裁切。
- 画面运动与预期推近/拉远一致。

### 9.3 旋转关键帧

1. 在首帧设置旋转为 `0`。
2. 在末帧设置小幅旋转。
3. 播放并逐帧检查。

**人工观察**

- 旋转方向正确。
- 旋转中心稳定。
- 旋转不会导致图层突然跳位或消失。

### 9.4 透明度关键帧

1. 在首帧设置透明度为 `0`。
2. 在后续帧设置为 `100%`。
3. 播放透明度变化。

**人工观察**

- 图层从不可见到可见连续变化。
- 不会在关键帧之间闪烁。
- 透明度运动与淡入淡出不会重复叠加出错误结果。

### 9.5 Replace 和 Append

1. 为图层写入第一组关键帧。
2. 使用替换方式写入第二组关键帧。
3. 播放确认旧动画已被替换。
4. 使用追加方式添加一段新的关键帧。
5. 播放完整时间范围。

**人工观察**

- Replace 不会保留旧关键帧造成双重运动。
- Append 只添加明确的新段落。
- 关键帧顺序和时间边界正确。
- 追加后没有突然跳帧或重复帧。

## 10. 缓动、循环和锚点

### 10.1 缓动

分别对相同起止位置测试：

1. `linear`。
2. `ease-in`。
3. `ease-out`。
4. `ease-in-out`。

**人工观察**

- 四种运动速度曲线有可见差异。
- `linear` 速度相对均匀。
- `ease-in` 起步较慢。
- `ease-out` 收尾较慢。
- `ease-in-out` 起止较慢、中间较快。
- 不同缓动不会改变起止姿态。

### 10.2 Repeat 循环

1. 创建一段有明显起止差异的运动。
2. 设置 `repeat`。
3. 播放跨越两个以上循环。

**人工观察**

- 每次循环从预期起点开始。
- 循环衔接处没有多余停顿或跳变。
- 播放到工程末尾后不会越界显示。

### 10.3 Ping-Pong 循环

1. 创建从左到右的运动。
2. 设置 `ping-pong`。
3. 播放两个以上往返周期。

**人工观察**

- 图层从起点运动到终点，再返回起点。
- 往返连接没有跳变。
- 周期长度和预期一致。

### 10.4 锚点

1. 将锚点设置在中心。
2. 进行缩放和旋转。
3. 将锚点改到左侧或目标人物关节附近。
4. 再次进行缩放和旋转。

**人工观察**

- 锚点改变后，缩放和旋转中心随之改变。
- 锚点变化不会破坏图层初始对齐。
- 刷新页面后锚点设置保持一致。

## 11. 图层运动和 Shot 镜头运动

### 11.1 运动叠加

1. 给人物或 Cutout 添加位置运动。
2. 给所属 Shot 添加镜头运动。
3. 播放运动叠加结果。
4. 删除其中一种运动，再比较画面。

**人工观察**

- 图层运动和镜头运动同时生效。
- 两种运动不会互相覆盖错误。
- 删除图层运动后只剩镜头运动。
- 删除镜头运动后只剩图层运动。
- 首帧仍保持正确对齐。

### 11.2 镜头 Push 和 Pull

1. 对 Shot 应用 `camera-push`。
2. 播放首帧、中间帧和末帧。
3. 换成 `camera-pull`。
4. 再次播放。

**人工观察**

- Push 产生稳定的镜头推近。
- Pull 产生稳定的镜头拉远。
- 镜头焦点保持在设定区域。
- 画面没有明显黑边、跳动或错误裁切。

### 11.3 镜头 Pan

1. 对 Shot 应用 `pan-left`。
2. 播放并观察画面移动方向。
3. 换成 `pan-right`。
4. 再次播放。

**人工观察**

- 左移和右移方向正确。
- 镜头移动速度连续。
- 主体不会被错误移出画布。
- 结束帧仍然保持完整构图。

### 11.4 首帧保护

1. 给 Shot 和图层添加运动。
2. 逐帧查看 Shot 第 0 帧。
3. 隐藏 L0，只查看 Clean Plate 和 Cutout。

**人工观察**

- 首帧 Cutout 与原图位置一致。
- 不会一开始就出现非预期位移、缩放或旋转。
- L0 不会被错误地作为运动主体。

## 17. 保存、刷新、撤销和重做

1. 在 `AE-COMIC` 工程中完成导入图层、Clean Plate、关键帧、预设和 sprite。

3. 保存工程。
4. 刷新浏览器。
5. 重新打开工程。
6. 对最近操作执行撤销。
7. 再执行重做。

**人工观察**

- 刷新后工程不会回退或变成空工程。
- 图层、Shot、对白、字幕和音频仍在正确时间。
- 关键帧、循环、缓动、锚点和 sprite 状态没有丢失。
- Clean Plate、Cutout 和 L0 的关系保持一致。
- 撤销只撤销最近一次用户操作。
- 重做可以恢复撤销的操作。
- 撤销/重做不会产生重复图层、孤立资源或残留选区。

## 18. 批次规划

### 18.1 基本批次

1. 创建总时长超过 18 秒的工程。

4. 查看每个批次的起止帧和时长。

**人工观察**

- 每个批次时长不低于 5 秒且不高于 18 秒。
- 大多数批次接近 15～18 秒。
- 批次按时间顺序排列。
- 批次帧范围连续，没有遗漏或重复。
- Shot 不会在任意位置被不合理切断。

### 18.2 对白和转场保护

1. 在 Shot 边界附近放置一段对白。
2. 在 Shot 边界设置 crossfade。
3. 再次规划批次。

**人工观察**

- 批次不会从 crossfade 中间切开。
- 必要音频不会被截断。
- 批次调整后首尾画面仍然连续。

### 18.3 短工程和尾批

1. 创建总时长不足 5 秒的工程。
2. 执行项目垫长。
3. 创建一个会产生短尾段的长工程。
4. 重新规划批次。

**人工观察**

- 短工程按明确规则延长到至少 5 秒。
- 延长不会产生空白或无意义跳变。
- 尾批不会短于 5 秒。
- 重新平衡后所有批次仍在 5～18 秒内。

## 23. 结论

最终结论只能从以下三项中选择：

```text
□ AE 类动态漫画闭环通过，可进入实际制作
□ 核心流程通过，但存在局部失败，只允许内部试用
□ 未通过，不得宣称当前工程具备完整 AE 类动态漫画生产能力
```

以下情况不能单独作为通过依据：

- 只看到按钮或面板出现。
- 只看到工程 JSON 中存在 motion 字段。
- 只通过了单元测试或源码检查。
- 只在 Canvas 中显示正确，没有验证 Player、静帧或最终视频。
- 只成功渲染一个静态帧，没有验证运动和转场。
- 只生成 manifest，没有核对实际导出结果。
- 只验证单个 Shot，没有验证多 Shot、对白、批次和交付。
