# AE Layout Follow-up

> 参考基线：`public/keyframe-ae-layout.html`
>
> 本文记录当前真实实现中还没有覆盖的参考页功能。视觉布局已经先接入现有编辑器，后续实现功能时应继续复用现有 state、undo/redo 和 `PlayerRef`，不要再创建一套平行时间轴状态。

## 已接入

- AE 风格顶部菜单栏和工作区栏。
- 左侧资源栏的项目标题、项目/效果页签、素材搜索和紧凑列表。
- 中央合成标题栏、分辨率信息和预览区边界。
- 右侧效果控件展示区，读取当前选中图层的基础位置、尺寸、旋转和不透明度。
- 时间线标题栏、当前时间、FPS、搜索框和工具按钮外观。
- 时间线图层栏加宽，保留当前轨道拖拽、选择、锁定、隐藏和静音逻辑。
- 已有的 PS 图层编辑会话继续通过图层页签打开，不改变原有蒙版处理流程。

## 待实现功能

### 1. 顶部工作区

- 工作区页签需要真正切换布局：标准、动画、PS 图层、效果、颜色、音频。
- “新建工作区”和工作区菜单需要保存面板组合、尺寸和可恢复布局。
- 顶部菜单项需要接入命令菜单，而不是只显示文本。

### 2. 项目面板

- “效果”页签需要显示可搜索的效果/预设列表。
- 项目面板菜单需要支持排序、缩略图大小、导入选项和刷新。
- 素材需要显示更接近 AE 的类型、尺寸、时长、采样率和代理状态。
- 资源拖入时间线前需要显示有效放置位置和轨道预览。

### 3. 右侧效果控件

- 当前右侧 Transform 数值目前是只读展示，尚未绑定编辑输入。
- Stopwatch 目前只是状态提示，尚未创建、删除或切换 `motion.transform.keyframes`。
- 需要支持 Position、Scale、Rotation、Opacity 的逐属性编辑。
- 修改当前帧时必须区分“创建当前帧关键帧”和“修改整段基础值”。
- 多选图层时需要展示共同值和混合值 `—`。
- 没有选中图层时，效果区需要支持合成级属性或稳定空状态。

### 4. AE 时间线

- 当前时间线仍然以现有轨道模型为主，尚未完整绘制 AE 的 `Layer -> Transform -> Property` 属性树。
- 需要把 Position、Scale、Rotation、Opacity 的属性行与右侧关键帧区域严格对齐。
- 需要显示由 frame 映射的菱形关键帧，支持选择、拖动、删除、复制和粘贴。
- 需要实现播放头拖动、关键帧前后跳转、工作区入点/出点和时间轴搜索过滤。
- “父级与链接 / 模式”切换目前只有现有编辑器能力，尚未按参考页做完整列切换。
- 图表编辑器按钮、关键帧导航按钮和时间轴面板菜单目前没有对应行为。
- 时间轴缩放应保留当前滚动位置，并且保证播放头和关键帧坐标不漂移。

### 5. 合成预览工具栏

- 网格和参考线、区域裁剪、相机工具、预览分辨率需要绑定现有 viewport / quality preview 状态。
- 合成页签与图层编辑页签需要统一支持关闭、重排和未保存标记。
- 右侧分镜浮层与效果控件需要可配置显示/隐藏，避免互相遮挡。

### 6. PS 图层工作区

- 参考 HTML 的独立 PS workspace 页签还没有接入顶部工作区切换。
- 现有 `LayerPanel` 已有画笔、快速选择、蒙版和导出逻辑，后续只需把它接入独立 workspace chrome。
- PS 工具栏的选择操作、视图模式、输出设置和坐标提示需要统一到参考页的面板密度。
- 需要补充工作区切换时的未保存 session 提示和恢复策略。

### 7. 交互和验收

- 所有暂不支持的 AE 控件应使用禁用态或明确提示，不能显示点击后无反馈的假按钮。
- 需要补充 1180px、1440px、1920px 宽度下的布局截图验收。
- 需要补充时间线缩放、侧栏拖拽、右侧效果区和 PS 图层会话的回归测试。
- 需要验证浅色主题不会破坏 AE 深色布局；如果产品最终只保留深色工作区，应在主题入口处明确限制。
