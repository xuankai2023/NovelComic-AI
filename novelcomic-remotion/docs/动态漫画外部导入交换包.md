# 动态漫画外部导入交换包

当前支持三种外部导入路径：

| 来源 | 交换格式 | API |
| --- | --- | --- |
| PSD 分层 | `psd-layer-manifest` | `/api/compose/psd/import` |
| After Effects | `novelcomic-ae-exchange` | `/api/compose/after-effects/import` |
| Live2D 预渲染结果 | `novelcomic-live2d-render` | `/api/compose/live2d/import` |

所有素材 URL 必须是 HTTPS，且服务端必须将域名加入
`COMIC_ALLOWED_REMOTE_HOSTS`。

## AE 交换包

最小结构：

```json
{
  "format": "novelcomic-ae-exchange",
  "version": 1,
  "packageId": "scene-001",
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "durationInFrames": 90,
  "assets": [
    {
      "id": "character",
      "type": "image",
      "remoteUrl": "https://cdn.example.com/character.png",
      "width": 800,
      "height": 900
    }
  ],
  "layers": [
    {
      "id": "character",
      "name": "Character",
      "type": "image",
      "assetId": "character",
      "from": 0,
      "durationInFrames": 90,
      "zIndex": 0,
      "visible": true,
      "locked": false,
      "transform": {
        "x": 500,
        "y": 80,
        "width": 800,
        "height": 900,
        "scaleX": 1,
        "scaleY": 1,
        "rotation": 0,
        "opacity": 1,
        "anchorX": 0.5,
        "anchorY": 0.5
      }
    }
  ]
}
```

支持的 AE 图层类型：

- `image`
- `video`
- `audio`
- `text`

图层可以增加：

- `parentId`
- `motion.keyframes`
- `motion.loop`
- `blendMode`
- `semantic`

表达式、插件、3D、Puppet、复杂粒子和其他未定义字段不会被执行；导入响应的
`importReport.warnings` 会说明降级边界。

## Live2D 渲染包

Live2D 不在编辑器中运行模型、物理和参数系统。先在外部渲染透明视频或图片，再包装为：

```json
{
  "format": "novelcomic-live2d-render",
  "version": 1,
  "packageId": "hero-live2d",
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "durationInFrames": 150,
  "assets": [
    {
      "id": "hero-render",
      "type": "video",
      "remoteUrl": "https://cdn.example.com/hero-alpha.webm",
      "width": 1080,
      "height": 1920,
      "durationInFrames": 150,
      "hasAudioTrack": false
    }
  ],
  "layers": [
    {
      "id": "hero-render",
      "name": "Hero Live2D Render",
      "type": "video",
      "assetId": "hero-render",
      "from": 0,
      "durationInFrames": 150,
      "zIndex": 0,
      "visible": true,
      "locked": false,
      "transform": {
        "x": 0,
        "y": 0,
        "width": 1080,
        "height": 1920,
        "scaleX": 1,
        "scaleY": 1,
        "rotation": 0,
        "opacity": 1,
        "anchorX": 0.5,
        "anchorY": 0.5
      }
    }
  ]
}
```

Live2D 包只接受图片和视频层。口型、眨眼和表情应在外部渲染后作为视频或按时间切换的图片层提供。

## PSD manifest

PSD 导入采用外部 PSD 转换器输出的分层 manifest，不在 Next.js 浏览器端解析大 PSD 二进制。manifest 的每个 layer 至少包含：

- `id`
- `name`
- `visible`
- `opacity`
- `zIndex`
- `bounds`
- `imageUrl`

导入时还需要：

- `projectId`
- `shotId`
- `sourceUrl`
- 目标工程中已经存在对应 Shot

PSD 的 layer styles、复杂 adjustment、blend mode 和部分 mask 应在转换阶段烘焙或降级。
