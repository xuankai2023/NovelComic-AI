# 动态漫画 Photoshop 类功能人工校验步骤

> 适用工程：`novelcomic-remotion`  
> 用途：只记录需要人工在浏览器中操作、观察 Canvas/Player、刷新页面或核对最终画面的部分。  
> 说明：数据模型、算法、领域函数、导出结构、渲染函数和已有单元测试不在本清单重复验证。

## 0. 校验准备

### 0.1 测试素材

使用固定素材目录：

```text
tests/fixtures/comic-ps-loop/
```

至少准备：

- `source.png`
- `source-with-hair-mouth.png`
- `background.png`
- `expected-clean-plate.png`
- `expected-recomposed.png`

### 0.2 每一步的记录方式

每个功能只记录以下结果：

- `通过`：操作完成，画面和状态都符合预期。
- `失败`：操作完成但结果错误。
- `阻塞`：入口不存在、页面报错或无法继续。
- `不适用`：当前版本没有该功能入口。

发现失败时记录：

1. 使用的素材和工程。
2. 操作到第几步。
3. 预期结果和实际结果。
4. 截图或录屏。
5. 刷新页面后是否仍能复现。

## 1. 工程初始化和原图基线

### 1.1 创建工程

1. 启动编辑器，打开动态漫画编辑页面。
2. 创建一个空白工程和一个测试镜头。
3. 导入 `source.png`。
4. 将原图放入镜头，并命名为 `L0 Source`。
5. 保存工程。

**人工观察**

- 原图完整显示，没有被拉伸、裁切或偏移。
- Canvas 和图层面板都能看到原图。
- 图层面板、Canvas、Player 没有明显初始化报错。
- 保存后刷新页面，工程仍能打开，原图仍在原来的位置。

**通过标准**

- 原图在保存前后位置、尺寸和画面一致。
- 后续功能可以在这个工程副本中继续操作。

## 2. 多边形描点拆层

### 2.1 描点和路径编辑

1. 选中 `L0 Source`，进入描点/多边形工具。
2. 在头发或嘴巴边缘连续点击，形成闭合轮廓。
3. 拖动一个点，确认路径实时跟随。
4. 删除一个点，再补回一个点。
5. 缩放并平移 Canvas。
6. 继续拖动路径点。
7. 取消一次未完成路径，再重新开始。

**人工观察**

- 点击位置和路径位置一致。
- 缩放、平移后，路径仍贴合原图目标，不发生整体漂移。
- 拖动点不会误触发图层移动。
- 删除、补点、闭合和取消操作的界面状态正确。
- 取消未完成路径后没有出现空图层或残留选区。

### 2.2 生成透明图层

1. 用闭合路径生成拆层。
2. 在图层面板选中新图层。
3. 暂时隐藏 `L0 Source`。
4. 单独查看 cutout。
5. 恢复 `L0 Source`。
6. 将 cutout 移动少量距离，再撤销移动。

**人工观察**

- 新图层出现在正确的镜头和图层位置。
- cutout 只显示目标区域，背景透明。
- cutout 初始位置与原图目标位置重合。
- 图层面板与 Canvas 的选中、显示状态同步。
- 移动、撤销后画面状态正确。

## 3. Clean Plate、重组和画面质量

### 3.1 Clean Plate 人工确认

1. 以头发或嘴巴图层为目标，生成 clean plate。
2. 在有/无原图、mask、cutout 的状态之间切换。
3. 查看 clean plate 预览。
4. 确认 clean plate 后隐藏或替换原图底图。
5. 移动目标图层约 `10 px`。
6. 旋转或缩放目标图层。
7. 对比目标图层移动前后的位置。

**人工观察**

- clean plate 覆盖的是被拆出区域，不误伤周围内容。
- 原图隐藏后，背景仍然完整。
- 目标图层移动后，原位置没有残影。
- 原位置没有透明洞、纯色块、明显涂抹痕迹或接缝。
- 新位置边缘没有明显黑边、白边或错误裁切。
- 人物与背景的前后遮挡关系正确。

**通过标准**

- 目标图层可以独立移动、缩放、旋转。
- 原位置和新位置都符合预期。
- 画面没有必须依赖原图显示才能掩盖的问题。

### 3.2 质量预览

1. 打开质量预览、差异预览或 overlay 功能。
2. 依次查看原图、重组图、差异图和透明洞提示。
3. 将目标图层移动到容易暴露背景的位置。
4. 再次查看质量预览。

**人工观察**

- 预览切换显示的是对应画面，而不是空白或旧画面。
- overlay 能帮助定位原图与重组图的偏差。
- 差异区域与实际画面问题一致。
- 运动后暴露区域能被明确看到或标记。

## 4. 魔棒选择

### 4.1 选择效果

1. 使用包含纯色背景和非连通同色区域的素材。
2. 选择魔棒，在连续区域点击。
3. 分别开启和关闭 `contiguous`。
4. 设置低、中、高三个容差并重复点击。
5. 生成透明图层。

**人工观察**

- `contiguous` 开启时只选择相连区域。
- `contiguous` 关闭时，其他符合颜色的非连通区域按预期被选中。
- 容差变化会带来可见的边界变化。
- 选区预览没有明显偏移、空白或选反。
- 生成的透明图层位置与原图一致。

### 4.2 异常操作

1. 点击透明区域。
2. 点击边缘抗锯齿区域。
3. 使用最小和最大容差。
4. 取消选择，再重新选择。

**人工观察**

- 页面不会崩溃或卡死。
- 无效选择有明确反馈。
- 取消后不会残留旧选区或错误图层。

## 5. 色彩范围选择

1. 进入色彩范围工具。
2. 点击目标颜色。
3. 调整范围、容差或相似度参数。
4. 查看选区预览。
5. 添加或移除颜色样本。
6. 生成透明图层。

**人工观察**

- 选区随参数调整实时变化。
- 相近颜色被纳入的范围符合预期。
- 添加样本会扩大目标范围，移除样本会缩小范围。
- 目标区域边界没有明显偏移。
- 生成图层后，图层初始位置和画面结果正确。

## 6. 钢笔工具

### 6.1 路径编辑

1. 进入钢笔工具。
2. 创建直线锚点。
3. 创建曲线锚点并拖动控制柄。
4. 移动、删除和补充锚点。
5. 闭合路径。
6. 缩放、平移 Canvas 后继续编辑。

**人工观察**

- 锚点、控制柄和曲线显示清楚。
- 曲线拖动方向符合鼠标操作。
- 路径闭合后没有断线或异常跳点。
- 缩放和平移后路径仍与目标边缘对齐。

### 6.2 路径进入拆层

1. 将钢笔路径转换为选区或 mask。
2. 生成透明图层。
3. 隐藏原图查看 cutout。
4. 恢复原图并移动 cutout。

**人工观察**

- 路径转换入口可用，结果不是空选区。
- 生成的图层只包含路径内目标内容。
- cutout 初始位置正确。
- 后续 clean plate 和移动效果与多边形描点流程一致。

## 7. 图层面板和图层操作

### 7.1 面板同步

1. 创建至少两个拆出图层和一个原图图层。
2. 在图层面板逐个选择图层。
3. 在 Canvas 点击图层或画面对象。
4. 在 Player 中查看当前画面。

**人工观察**

- 面板选中项、Canvas 选中框和实际目标一致。
- 选中不同图层时，不会错选或显示旧对象。
- 面板操作会立即反映到 Canvas 和 Player。

### 7.2 基础操作

分别对一个拆出图层执行：

1. 重命名。
2. 隐藏和显示。
3. 锁定和解锁。
4. 上移、下移或拖动排序。
5. 复制。
6. 删除。

**人工观察**

- 重命名立即同步到所有显示位置。
- 隐藏/显示真实影响 Canvas 和 Player。
- 锁定后不能误拖动或编辑；解锁后恢复。
- 排序改变后，遮挡关系随之改变。
- 复制品能独立选择和移动，不会联动原图层。
- 删除后画面、面板和时间线没有残留。

## 8. 图层分组

1. 创建一个组，将两个拆出图层放入组内。
2. 展开和折叠组。
3. 隐藏和显示组。
4. 锁定和解锁组。
5. 将子图层移出组。
6. 删除组，并观察子图层处理结果。

**人工观察**

- 子图层归属和缩进关系正确。
- 组隐藏会影响所有子图层。
- 组锁定会阻止组内对象被误操作。
- 折叠只改变面板展示，不会丢失子图层。
- 解组或删除组后，子图层不会无故消失或重复。

## 9. 调整图层

1. 创建调整图层并绑定到目标图层或组。
2. 调整亮度、对比度、色相等可用参数。
3. 调整作用范围。
4. 创建第二个调整图层。
5. 调整两个调整图层的顺序。
6. 隐藏和显示每个调整图层。

**人工观察**

- 参数变化会真实改变目标画面。
- 调整图层只影响设定范围。
- 调整图层顺序变化会产生可见的叠加顺序变化。
- 隐藏调整图层能恢复调整前画面。
- Canvas、Player 和静帧预览效果一致。

## 10. 图层搜索

1. 创建或导入多个不同名称的图层。
2. 输入完整名称、部分名称和不存在的关键词。
3. 清空搜索框。
4. 在搜索结果中选择、隐藏、锁定或删除图层。

**人工观察**

- 搜索结果准确过滤。
- 搜索结果为空时界面状态正常。
- 清空搜索后所有图层恢复显示。
- 搜索不会改变图层顺序、显示状态或锁定状态。
- 搜索结果中的操作作用于正确图层。

## 11. 动画和时间线

### 11.1 Cutout 运动

1. 给头发或嘴巴图层添加位置、缩放或旋转动画。
2. 播放时间线。
3. 查看首帧、中间帧和末帧。
4. 将播放头拖动到关键帧附近反复查看。

**人工观察**

- 首帧目标图层与原图位置对齐。
- 运动连续，没有突然跳动、闪烁或回到错误位置。
- 关键帧附近没有透明洞、残影或图层消失。
- Canvas 预览与 Player 播放结果一致。

### 11.2 眨眼和口型

1. 给角色添加眨眼或口型切换。
2. 播放包含切换的时间段。
3. 逐帧查看切换前、切换帧和切换后。

**人工观察**

- 资源在预期帧切换。
- 切换没有闪白、闪黑、错位或透明空洞。
- 眨眼、嘴型和其他头部运动不会互相覆盖错误。
- 保存重载后切换时间仍一致。

## 12. 保存、重载、撤销和重做

1. 在同一个工程中完成一次拆层、clean plate、分组、排序和动画操作。
2. 保存工程。
3. 刷新浏览器。
4. 重新打开工程。
5. 检查图层、画面、时间线和参数。
6. 连续执行几次撤销。
7. 再连续执行几次重做。

**人工观察**

- 刷新后工程不会退回旧状态或变成空工程。
- 图层顺序、显示/锁定状态、组结构和调整参数保持一致。
- clean plate、cutout 和动画画面保持一致。
- 撤销只撤销最近一次用户操作。
- 重做能恢复被撤销的操作。
- 撤销/重做过程中没有重复图层、残留选框或画面闪烁。

## 13. 导出和最终画面

### 13.1 浏览器导出操作

1. 从已完成工程执行 LayerPackage、manifest 或工程包导出。
2. 等待导出完成。
3. 下载并解压导出包。
4. 用导出结果重新打开或继续预览。

**人工观察**

- 导出按钮有明确的进行中、成功和失败状态。
- 导出过程中页面不会误报成功。
- 下载文件可打开，文件名和工程对应。
- 导出结果重新打开后，图层关系和画面不明显变化。

### 13.2 首帧、中间帧、末帧

1. 记录工程总时长。
2. 查看首帧、中间帧和末帧。
3. 分别比较 Canvas、Player、静帧预览和最终视频。
4. 重点查看头发、嘴巴、遮挡关系和字幕/对白边界。

**人工观察**

- 三个时间点都能正常显示。
- 没有空白帧、黑帧、旧帧残留或资源加载失败。
- Canvas、Player、静帧和最终视频的构图、图层顺序和坐标一致。
- 动画不会在视频开头或结尾突然跳变。
- 对白、音频和画面切换没有明显错位。

## 14. 一次完整人工回归

按以下顺序只做一遍完整操作：

1. 创建工程并导入原图。
2. 用多边形描点拆出头发。
3. 生成并确认 clean plate。
4. 移动头发并检查原位置。
5. 用魔棒拆出背景或其他区域。
6. 用色彩范围生成一个选区。
7. 用钢笔工具生成一个选区。
8. 将多个图层分组、排序、隐藏和锁定。
9. 添加一个调整图层。
10. 添加头发运动、眨眼或口型。
11. 保存并刷新页面。
12. 撤销并重做一项操作。
13. 导出工程包。
14. 查看首帧、中间帧和末帧。

**最终通过标准**

- 每个功能入口都能完成对应人工操作。
- 面板、Canvas、Player、时间线和保存后的工程状态一致。
- 拆层后的运动没有残影、透明洞、错位或错误遮挡。
- 刷新、撤销、重做和导出不会丢失用户可见结果。
- 首帧、中间帧、末帧和最终视频都没有明显画面异常。
