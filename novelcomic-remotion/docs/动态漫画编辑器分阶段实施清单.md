## 4. 每步统一验收命令

```bash
pnpm typecheck
pnpm test
pnpm build
```

某项命令失败时：

1. 先确认是本轮回归还是已有问题。
2. 本轮回归必须修复后再继续。
3. 已有问题必须记录命令、错误、影响和临时结论。
4. 不得为了通过测试删除或跳过原有有效用例。
