# 动态漫画 Photoshop 类功能完整闭环测试清单

> 适用工程：`novelcomic-remotion`  
> 文档性质：功能验收、回归测试和浏览器手工测试规范  
> 测试目标：确认 Photoshop 类操作不是“按钮能点击”，而是能够产生正确的图层、蒙版、底图、动画、工程状态、导出文件和最终渲染结果。  
> 状态约定：`待测`、`通过`、`失败`、`阻塞`、`不适用`

## 1. 测试结论规则

### 1.1 完整闭环定义

动态漫画的 Photoshop 类功能必须完成下面的完整链路：

```text
上传原图
→ 创建工程和镜头
→ 使用选择工具得到选区或路径
→ 生成 mask
→ 根据 mask 生成透明 cutout 图层
→ 记录原图坐标、bounds 和锚点
→ 生成或应用 clean plate
→ 将结果接入图层、素材、item、track 和镜头
→ 在图层面板中管理图层
→ 创建分组并应用调整图层
→ 在 Canvas 中移动或制作动画
→ 检查重组画面、透明洞和原图重影
→ 保存工程
→ 刷新或重新加载工程
→ 验证状态和画面仍然一致
→ 导出 LayerPackage、manifest 和工程包
→ 渲染首帧、中间帧和末帧
→ 验证最终图片和视频结果
```

任意一项只完成 UI 状态变化、没有实际资产或最终画面结果，都不能判定为通过。

### 1.2 通过条件

单个测试只有在以下项目全部满足时才能标记为 `通过`：

- 操作入口存在，且可以完成规定的用户操作。
- 工程状态确实发生了正确变化，而不是只改变按钮样式。
- `mask`、`cutout`、`clean plate`、`asset`、`item`、`track` 和镜头引用关系完整。
- 图层初始位置与原图中的位置一致。
- 图层可见性、锁定、顺序、分组和调整效果真正影响 Canvas。
- 保存后重新加载，数据、资源引用和画面结果不丢失。
- 导出包包含需要的图片、蒙版、manifest 和工程 JSON。
- Player、静帧和最终渲染使用相同的图层顺序和坐标协议。
- 移动头发、嘴巴等拆出图层后，不出现原位置重影、透明洞或错误遮挡。

### 1.3 不能作为通过依据的结果

以下结果只能说明“部分逻辑存在”，不能说明功能闭环完成：

- 点击工具按钮后出现了选中状态。
- 单元测试通过，但浏览器中没有产生图层。
- 图层面板显示了名称，但 Canvas 没有同步。
- 工程 JSON 中有 `cutoutAssetId`，但素材下载失败。
- 导出了 `manifest.json`，但 PNG 没有进入 ZIP。
- 预览时画面正确，但刷新后图层消失。
- 静态帧正确，但移动图层后出现底图残留。
- 调整图层参数改变了数字，但没有改变目标图层画面。

## 4. 统一数据和像素判定标准

### 4.1 坐标协议

- polygon 使用原图像素坐标。
- mask 尺寸必须与原图尺寸一致。
- cutout 使用 polygon 或 mask 的紧边界尺寸。
- cutout 的 `bounds` 必须记录其在原图中的位置。
- composition 坐标只在 Canvas、Player 或导出时转换。
- 缩放、平移、contain、zoom 不得改变原图坐标结果。

### 4.2 alpha 判定

- 选区外 alpha 必须为 `0`。
- 选区内非透明像素必须被保留。
- 边缘像素必须保持合理的抗锯齿 alpha，不得全部变成硬黑边或透明。
- mask 白色区域表示保留，黑色区域表示透明；若使用反向约定，必须在整个链路中保持一致。
- cutout 不得把整张原图重新存入独立图层。

### 4.3 对齐判定

- 静态 cutout 放回原图位置后，边界偏差不超过 `1 px`。
- 若使用 composition 缩放，允许误差按缩放比例换算，但原图坐标仍需精确。
- 头发或嘴巴移动前，cutout 与原图对应区域重合。
- 头发或嘴巴移动后，原位置必须由 clean plate 填补。

### 4.4 画面差异判定

测试报告必须记录使用的比较方式：

- 像素差异图。
- alpha 差异图。
- overlay 对齐图。
- difference 混合图。
- 首帧、中间帧、末帧截图。

静态重组图与 `expected-recomposed.png` 的差异阈值由素材尺寸确定，但必须在测试报告中填写具体数值，不能只写“看起来差不多”。

## 5. 测试执行前的工程基线

### PS-000 工程初始化和原图基线

**目的**：确认后续所有操作有稳定的原图、镜头、素材和坐标基线。

**前置条件**

- 已启动应用。
- 已准备 `source.png`。
- 浏览器开发控制台无初始化错误。

**操作步骤**

1. 上传 `source.png`。
2. 创建一个测试工程和一个测试镜头。
3. 将原图放入镜头。
4. 记录原图资产 ID、item ID、track ID、图片宽高、Canvas 宽高和缩放比例。
5. 将原图命名为 `L0 Source`。
6. 保存工程。

**状态检查**

- 原图只有一个源素材引用。
- 原图 item、track 和镜头关系完整。
- 原图未被裁切、旋转或添加运动。
- 原图尺寸和 source canvas 尺寸可读取。
- 原图仍然可以在后续步骤中恢复。

**画面检查**

- Canvas 显示完整原图。
- 原图没有被拉伸、裁剪或偏移。
- 首帧截图与固定基线截图一致。

**通过标准**

- 原图和工程基线可重复恢复。
- 后续测试可以使用同一个工程复制出的干净副本。

## 6. 描点拆层闭环

### PS-001 多边形描点和路径编辑

**目的**：确认用户可以在 Canvas 上准确描出头发或嘴巴区域，并且操作坐标与原图坐标一致。

**前置条件**

- 完成 PS-000。
- 当前选中 `L0 Source`。
- 已进入描点拆层工具。

**操作步骤**

1. 点击头发区域的第一个点。
2. 连续添加不少于 3 个点，覆盖完整头发轮廓。
3. 拖动一个控制点。
4. 删除一个控制点。
5. 在原位置增加一个新点。
6. 缩放 Canvas。
7. 平移 Canvas。
8. 继续添加或拖动控制点。
9. 闭合 polygon。
10. 取消一次未完成路径，再重新描点。
11. 保存当前工程。

**状态检查**

- polygon 至少包含 3 个合法点。
- 点坐标是原图坐标，不是当前屏幕坐标。
- 所有点均在 source canvas 范围内。
- 不存在 `NaN`、`Infinity` 或超出边界的点。
- 缩放、平移前后，同一控制点的原图坐标不发生漂移。
- 取消未完成路径不会产生孤立图层或孤立资产。

**画面检查**

- 路径显示在正确的头发边缘上。
- 半透明选区预览覆盖目标区域。
- 路径不会穿透到 Canvas 普通拖动逻辑。
- 闭合后起点和终点连接正确。

**失败判定**

- 缩放或平移后描点偏离原图。
- 点击一次生成多个点或误触发图层移动。
- 删除点后路径断裂但 UI 仍显示已闭合。
- 取消路径后出现空图层。

### PS-002 描点生成 mask、cutout 和图层

**目的**：确认描点结果可以真正转换为可动画的透明图层。

**操作步骤**

1. 使用 PS-001 完成头发 polygon。
2. 确认选区预览。
3. 执行生成图层或拆层。
4. 等待 mask 和 cutout 资产生成。
5. 在图层面板中查看新图层。
6. 暂时隐藏原图，检查 cutout。
7. 恢复原图显示。
8. 将头发图层移动少量距离。

**状态检查**

- `ComicEditLayer` 或等价数据存在。
- `sourceAssetId` 指向原图资产。
- `maskAssetId` 指向原图尺寸的 mask。
- `cutoutAssetId` 指向透明 cutout。
- `sourceItemId`、item、track 和 shot 引用完整。
- `bounds` 是目标区域在原图中的紧边界。
- `polygon` 被保存。
- 新图层默认可见、未锁定、透明度为 `1`。
- 未产生重复的孤立 item、track 或 asset。

**像素检查**

- mask 选区外为黑色或 alpha `0`。
- cutout 选区外 alpha 为 `0`。
- cutout 选区内保留头发像素。
- cutout 尺寸等于 bounds 尺寸。
- cutout 放回 bounds 后与原图头发位置重合。

**画面检查**

- cutout 初始位置与原图位置完全一致。
- 原图仍然保留显示。
- 头发图层移动后，若尚未生成 clean plate，必须能明确看到原图残留；该状态只能作为待处理状态，不能作为最终通过结果。

### PS-003 clean plate、重组和运动后检查

**目的**：确认拆出的头发或嘴巴移动后，原位置不会出现重影或透明洞。

**操作步骤**

1. 以 PS-002 的头发图层为目标。
2. 生成 clean plate，或调用已接入的填图流程。
3. 查看原图、clean plate、mask 和 cutout 的对比预览。
4. 验证 clean plate 后再隐藏或替换原图。
5. 移动头发图层 `10 px`。
6. 旋转头发图层少量角度。
7. 检查原头发位置和新头发位置。
8. 恢复头发位置并保存。

**状态检查**

- clean plate 资产尺寸与 source canvas 相同。
- `cleanPlateAssetId` 已写入对应图层。
- 原始 source asset 仍然可恢复。
- 只有 clean plate 通过检查后才允许把原图作为最终底图隐藏或替换。
- 失败的补图不会破坏原图，也不会丢失原始 source asset。

**画面检查**

- clean plate 已移除头发区域。
- 头发移动后原位置没有头发残留。
- 原位置没有透明洞。
- 新位置的头发边缘没有明显黑边或错误裁切。
- 头发和底图之间的遮挡关系正确。

**通过标准**

- 头发可以独立移动、缩放和旋转。
- 原位置和新位置都得到正确画面。
- 质量预览没有暴露区域。
- 保存重载后仍然保持相同结果。

## 7. 魔棒闭环

### PS-004 魔棒基础选择

**目的**：确认魔棒不是只产生选中状态，而是可以根据连续颜色区域生成正确 mask 和图层。

**前置条件**

- 使用包含纯色背景和同色非连通区域的素材。
- 选择魔棒工具。

**操作步骤**

1. 在连续纯色背景区域点击。
2. 记录默认容差下的选区。
3. 开启 `contiguous`，重新选择。
4. 关闭 `contiguous`，重新选择。
5. 分别设置低、中、高三个容差。
6. 生成 mask。
7. 根据 mask 生成 cutout。
8. 生成名为 `Background Extracted` 的图层。

**状态检查**

- 选区实际被写入 mask，而不是只保存在临时 UI 状态。
- `contiguous=true` 时只选中与点击点连通的目标区域。
- `contiguous=false` 时，符合颜色范围的非连通区域按预期纳入。
- 容差改变时，mask 像素数量和边界会合理改变。
- 生成图层后拥有完整的 asset、item、track 和 layer metadata。

**像素和画面检查**

- 目标纯色区域被完整选择。
- 不同颜色区域不被误选。
- 连通和非连通结果符合开关设置。
- 选区外 alpha 为 `0`。
- 生成的图层放回原位后与原图目标区域一致。

**边界测试**

- 点击透明区域。
- 点击不存在的像素区域。
- 容差为最小值。
- 容差为最大值。
- 图片存在相近颜色和抗锯齿边缘。

**失败判定**

- 只显示虚线选区，没有 mask 或 cutout。
- 改变容差但输出 mask 不变。
- `contiguous` 开关没有实际影响。
- 生成的图层位置与原图不一致。

### PS-005 魔棒进入动态漫画链路

**操作步骤**

1. 用魔棒从背景或线稿中选择区域。
2. 生成透明图层。
3. 生成对应 clean plate。
4. 将新图层放入 `Character Parts` 组。
5. 为图层添加位置或透明度动画。
6. 保存、重新加载、导出和渲染。

**通过标准**

- 魔棒生成的图层与手动描点生成的图层使用相同的图层关系。
- 动画前后没有错误底图、空洞或未上传资源。
- 导出 manifest 中能找到该图层和对应文件。

## 8. 色彩范围闭环

### PS-006 色彩范围选择和预览

**目的**：确认色彩范围可以选中相似颜色，而不是只选中一次点击的单个像素。

**操作步骤**

1. 选择色彩范围工具。
2. 点击头发或衣服的目标颜色。
3. 调整颜色范围或容差。
4. 打开选区预览。
5. 分别测试低、中、高范围。
6. 生成 mask。
7. 生成透明 cutout。

**状态检查**

- 预览会随颜色范围变化。
- 相似颜色区域逐步纳入。
- 明显不同的颜色被排除。
- mask 记录的是最终范围，而不是临时点击颜色。
- mask 尺寸等于原图尺寸。

**像素和画面检查**

- 目标区域的连续和非连续相似颜色按设计纳入。
- 颜色边缘保留合理 alpha。
- 生成 cutout 后选区外透明。
- 放回原图位置后目标区域与原图重合。
- 生成 clean plate 后移动 cutout 不出现重影或透明洞。

### PS-007 色彩范围边界和动态结果

**边界测试**

- 选择一个不存在的颜色。
- 选择与背景相近的颜色。
- 范围为最小值。
- 范围为最大值。
- 目标区域包含抗锯齿边缘。
- 目标区域包含透明像素。

**动态闭环**

1. 用色彩范围生成 `Hair Extracted`。
2. 接入 `hair-sway` 或位置关键帧。
3. 保存并重新加载。
4. 导出 LayerPackage。
5. 渲染首帧、中间帧和末帧。

**通过标准**

- 调整参数不会破坏已有 layer ID 和资源引用。
- 重新加载后 mask、cutout、clean plate 和动画仍然存在。
- 运动后没有暴露原图残留。

## 9. 钢笔工具闭环

### PS-008 锚点、曲线和路径编辑

**目的**：确认钢笔工具可以处理曲线边缘，并且路径数据可保存、可编辑。

**操作步骤**

1. 新建钢笔路径。
2. 添加多个锚点。
3. 拖动锚点的入柄和出柄，形成曲线。
4. 移动一个锚点。
5. 删除一个锚点。
6. 继续添加锚点。
7. 闭合路径。
8. 保存工程。

**状态检查**

- `penPaths` 中存在路径记录。
- 路径有稳定 ID 和名称。
- 锚点坐标为原图或约定的稳定坐标。
- 曲线控制柄被保存。
- `closed=true` 只在路径真正闭合后出现。
- 删除锚点不会留下无效引用。
- 保存重载后锚点、曲线和闭合状态一致。

**画面检查**
