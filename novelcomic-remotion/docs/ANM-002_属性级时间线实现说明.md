# [ANM-002] 属性级时间线

> 实施日期：2026-10-06

## 1. 本轮目标

- 当前状态：已有 Image Motion 关键帧数据、Inspector 编辑和最终渲染求值，但缺少 AE 风格属性级时间线主入口。
- 目标状态：图像图层可在 Timeline 展开 Transform 属性，通过秒表和菱形按钮管理当前帧关键帧。
- 本轮只做：Anchor Point、Position、Scale、Rotation、Opacity；属性行展开；秒表；当前帧关键帧增删；前后导航；P/S/R/T/A/U；Viewer Position 拖拽写入同一曲线。
- 本轮不做：Graph Editor 改版、贝塞尔手柄、多图层批量关键帧、效果属性、Auto-Key 默认开启。

## 2. AE 位置契约

- 主要参照：After Effects Timeline > Layer > Transform。
- 顶部菜单路径：无。
- 工具栏位置：无新增工具。
- 面板位置：底部 Timeline 为主入口；现有 Inspector 继续作为同一数据的辅助视图。
- 时间线位置：图层 disclosure triangle 下的 Transform 组和五个属性行。
- 快捷键：A / P / S / R / T 显示对应属性，U 显示已动画属性。
- Viewer 表现：Position 秒表开启后，画布拖拽新增或更新当前帧 Position 关键帧。
- 提交方式：每次秒表、菱形和导航相关编辑通过 UndoableState 的统一写入口提交；连续 Viewer 拖拽在指针抬起时合并为一次 Undo。

## 3. 状态与求值

- 状态 owner：`ImageItem.motion.transform`。
- 关键帧：`TransformKeyframe` 支持 `anchorX` / `anchorY`，并继续承载 Position、Scale、Rotation、Opacity。
- 秒表状态：`TransformAnimation.animatedProperties`；旧工程未包含该字段时从现有关键帧自动推断。
- 静态回退：关闭秒表时把当前求值写入 Transform 静态字段，避免画面跳回默认值。
- 求值入口：`evaluateTransformAtFrame`，编辑器预览和最终 Image 渲染共享同一插值结果。
- 持久化：字段位于既有 UndoableState 项目文档内，现有保存/加载路径自动序列化。

## 4. 失败与边界

- 锁定轨道禁用秒表和关键帧修改。
- 当前时间自动限制在图层有效时段内。
- 非图像图层不显示本轮 Transform 属性入口。
- capability flag：`FEATURE_PROPERTY_TIMELINE`。

## 7. 阶段 5：失败与诊断

### 7.1 统一数据流

- 诊断入口：`motion/diagnostics.ts`，统一返回 `code`、`message`、`repair`，并按场景附带 Item、属性、帧和 Asset。
- 写入入口：`updateTransformPropertyCommand` 负责值与帧校验；`updateTransformPropertyInState` 在最新 `EditorState` 上再次校验选择、Item 类型、删除、Track / Layer Group 锁定与隐藏状态。
- 求值入口不变：`evaluateTransformAtFrame` / `evaluateImagePose`。非法数据仍由校验器报告，求值器仅提供有限值安全回退，避免产生 `NaN`、无效透明度或非正 Scale。
- 渲染入口：预览帧、完整/远程提交和本地渲染都在提交 worker 或创建本地临时目录前执行同一 Transform / Sprite 诊断。

### 7.2 已覆盖失败场景

- 空选择、已删除 Item、非图像图层、锁定或隐藏 Track / Layer Group。
- 非整数、负数、`NaN`、`Infinity` 和 Item 范围外帧。
- 缺失 keyframes、非法静态值、重复关键帧、easing、hold、handle、loop、Scale 和 Opacity。
- 缺失素材、未就绪远程素材和错误 Sprite 素材类型或引用。
- Auto-Key 关闭时修改已动画属性。
- Viewer 连续拖拽的单次提示、指针取消、Escape、Undo、删除、锁定、隐藏和播放头变化取消。
- blocked 操作保持原 state 引用；中间拖拽不提交 Undo，完成时只提交一次。
- 诊断消息不包含签名 URL、完整请求体或内部堆栈。
