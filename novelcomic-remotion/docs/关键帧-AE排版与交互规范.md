# 关键帧 AE 排版与交互规范

> 适用工程：`novelcomic-remotion`  
> 交付方式：先完成布局和交互样稿，再接入现有 `EditorSidebar`、`Inspector` 和 `Timeline`。  
> 目标：关键帧相关界面在信息层级、控件位置、时间轴语义和操作反馈上与 After Effects 保持一致，不做“看起来像”但行为不同的简化版。

## 1. 先定方向

### 1.1 总体布局

编辑器保持三块主区域：

```text
┌────────────── 左侧栏 ──────────────┬────────────── 中央合成预览 ──────────────┐
│ 工具栏 52px                        │                                          │
│                                    │                                          │
│ 上传素材 / Project                 │                                          │
│ ────────────────────────────────   │                                          │
│ 素材卡片列表                       │                                          │
│                                    │                                          │
│ ── 从上传素材区下方切出：           │                                          │
│ 选中图层属性 / Transform           │                                          │
│ 关键帧状态和快速操作               │                                          │
├────────────────────────────────────┴──────────────────────────────────────────┤
│ AE 式 Timeline：图层、属性树、时间尺、工作区、关键帧菱形、播放头                │
└───────────────────────────────────────────────────────────────────────────────┘
```

左侧的“上传素材”区域只负责资产管理；素材下方切出的区域只负责当前选中图层的属性预览和关键帧入口。真正的关键帧编辑必须落在底部 Timeline，不能把关键帧点分散在素材卡片上。

### 1.2 AE 对齐原则

以下规则是硬约束：

1. 图层在左，时间尺和关键帧在右；不能把关键帧放在属性卡片的下方做成另一条孤立时间轴。
2. 属性使用可展开的树结构：图层 → Transform → Position / Scale / Rotation / Opacity。
3. 每一行属性右侧有独立的 stopwatch；开启后才进入动画状态。
4. 关键帧使用菱形标记，菱形的 x 坐标严格由 frame 映射，不由 DOM 子元素数量决定。
5. 当前时间指示器（CTI / playhead）贯穿时间尺和所有轨道，拖动它只改变当前帧，不改变关键帧数据。
6. 关键帧编辑、选中、删除、复制、粘贴、前后跳转都必须有明确的当前选中状态。
7. 当前帧修改已有动画图层时，默认修改或创建当前帧关键帧，不得静默写回整段基础值。
8. 关闭自动关键帧后，Inspector 必须明确显示“修改整段”，并且不会偷偷新增关键帧。
9. 隐藏、锁定、独奏、音频静音、连续栅格化/折叠变换等图层开关与 AE 的图层开关列保持同一顺序。
10. 任何不能实现的 AE 能力必须显示为禁用或降级状态，不能显示一个可点击但无效的假控件。

## 2. 左侧：上传素材下方切出的区域

### 2.1 区域尺寸

| 项目 | 规则 |
| --- | --- |
| 左侧栏工具列 | 固定 `52px`，不参与内容缩放 |
| 内容栏推荐宽度 | `320px`，可拖拽范围 `280px–420px` |
| 素材库高度 | 左侧内容区的 `56%–64%`，最小 `260px` |
| 关键帧属性区 | 素材库下方剩余空间，最小 `220px` |
| 属性区标题栏 | `36px`，固定在顶部 |
| 属性区滚动 | 仅属性内容滚动，标题栏和操作栏固定 |
| 素材卡片 | 2 列；内容不足一列时保持单列，不强行压缩缩略图 |

左侧内容栏高度不足时，优先保证关键帧属性区可见；素材库允许滚动，不允许把关键帧入口挤出首屏。

### 2.2 属性区排版

属性区显示当前选中 Item：

```text
关键帧 / Transform
Character.png                         [锁定] [更多]
────────────────────────────────────────
当前帧 00:00:01:12        [自动关键帧 ●]
────────────────────────────────────────
Transform                             [展开]
位置              X 540     Y 812      ◆
缩放              X 100%    Y 100%      ◆
旋转                         0°         ◆
不透明度                    100%        ◆
```

规则：

- 没有选中 Item 时，显示空状态，不显示误导性的默认数值。
- 选中多个 Item 时，显示“多选”，只展示有共同值的属性；存在混合值时显示 `—`。
- 位置、缩放、旋转、不透明度四组基础属性必须能跳转到底部 Timeline 对应行。
- 点击菱形按钮：
  - 没有动画：在当前帧创建关键帧并自动打开该属性的 stopwatch。
  - 已有动画：当前帧有关键帧则移除当前帧关键帧；当前帧无关键帧则新增当前值关键帧。
- 属性区的菱形是操作入口，不是第二套关键帧存储。数据仍然写入统一 `motion.keyframes`。
- 属性区不得出现时间轴缩略版，避免产生两个播放头和两个时间语义。

## 3. 底部：AE 式 Timeline

### 3.1 时间轴分区

Timeline 固定由四层组成：

```text
Toolbar       当前帧 / 播放控制 / 自动关键帧 / 关键帧导航 / 时间轴缩放
Time ruler    时间码、主刻度、次刻度、工作区范围
Layer panel   图层开关、图层名称、展开箭头、属性名称、stopwatch
Keyframe area 当前帧竖线、关键帧菱形、选区、拖拽和吸附
```

推荐尺寸：

| 项目 | 规则 |
| --- | --- |
| Timeline 最小高度 | `300px` |
| Toolbar | `40px` |
| Time ruler | `28px` |
| Layer panel 默认宽 | `300px`，可调整范围 `240px–480px` |
| 时间轴右侧内容 | 至少 `640px`；不足时水平滚动 |
| 图层行 | `28px` |
| 属性子行 | `24px` |
| 时间尺刻度 | 不得小于 `1px` 可点击宽度 |

### 3.2 图层开关列顺序

从左到右固定为：

```text
展开箭头
可见 Eye
锁定 Lock
独奏 Solo
音频 Audio/Mute
图层颜色
图层名称
```

这些列不能因为某个图层类型不同而重新排序。没有意义的开关显示禁用态并保留占位宽度，避免同一列在不同轨道上下跳动。

### 3.3 属性树

默认展开规则：

- 新增图层：默认展开到 `Transform`。
- 用户手动折叠后，保持折叠状态，不因播放或重新渲染自动展开。
- 图层没有关键帧时，属性行仍然显示；不能因为没有关键帧就隐藏属性。
- 只读或不支持的属性必须保留名称，并显示锁定/不可用状态。

第一期属性顺序：

```text
Transform
  Position
  Scale
  Rotation
  Opacity
```

后续按 AE 方式扩展：

```text
Anchor Point
Crop
Audio Levels
Masks
Effects
Parent & Link
Time Remap
Expressions
3D Transform
```

扩展属性不能改变已有属性的顺序，也不能插到 Position 和 Scale 中间导致用户的肌肉记忆失效。

### 3.4 关键帧语义

统一关键帧结构至少需要：

```ts
type Keyframe = {
  frame: number;
  value: number | [number, number] | [number, number, number];
  easing?: Easing;
  hold?: boolean;
  selected?: boolean;
};

type AnimatedProperty = {
  enabled: boolean;
  keyframes: Keyframe[];
};
```

必须满足：

- `frame` 是整数，范围为 `[item.from, item.from + item.durationInFrames - 1]`。
- 同一属性同一帧最多一个关键帧；新增时更新，不产生重复菱形。
- 属性之间可以稀疏存在，例如 Position 有动画而 Rotation 没有动画。
- 删除属性最后一个关键帧时，保留属性静态值；是否关闭 stopwatch 必须由用户明确决定。
- 关键帧排序按 frame 升序保存，显示按时间从左到右。
- 插值、hold、easing 由统一 evaluator 计算，Timeline 只负责显示和编辑。
- 首帧和尾帧不自动补关键帧，除非用户点击新增或导入数据明确提供。

### 3.5 当前帧写入规则

1. 图层没有该属性动画：
   - 自动关键帧打开：在当前帧创建第一个关键帧。
   - 自动关键帧关闭：修改静态值，作用于整个可见区间。
2. 图层已有该属性动画：
   - 自动关键帧打开：更新当前帧关键帧；没有则按当前评估值新增。
   - 自动关键帧关闭：Inspector 禁止直接写入动画属性，必须提示“请打开自动关键帧或编辑关键帧”。
3. 当前帧在 Item 的入点/出点之外：
   - 属性面板只读。
   - 不得创建越界关键帧。
4. 当前帧落在工作区之外但仍在合成范围内：
   - 可以编辑，不因工作区标记阻止操作。
5. Item 被锁定、轨道隐藏或项目只读：
   - 不创建、移动、删除关键帧。
   - 所有相关控件显示禁用态。

## 4. 交互细节

### 4.1 选中和定位

- 点击图层名称：选中图层，不改变展开状态。
- 点击属性行：选中属性，时间轴显示属性对应的关键帧。
- 双击属性行：进入数值编辑或聚焦 Inspector 对应字段。
- 点击左侧关键帧菱形：跳转到该帧并选中关键帧。
- 点击右侧关键帧菱形：在当前帧新增/删除该属性关键帧。
- 从属性区点击“在时间轴中显示”：展开对应图层和属性，并横向滚动到当前帧。

### 4.2 拖动关键帧

- 拖动前记录 `before` 快照，拖动中只更新 transient 状态。
- 拖动结束时一次性提交一个 Undo transaction。
- 默认按整数 frame 吸附；按住修饰键时允许临时关闭吸附，仍需最终落在整数 frame。
- 多选关键帧拖动保持相对帧间距。
- 拖动跨越 Item 边界时钳制到合法范围，不能把关键帧拖出 Item。
- 拖动导致两个关键帧落到同一帧时：
  - 单个拖动：后放置的关键帧覆盖先前关键帧，但必须进入 Undo。
  - 多选拖动：阻止合并并显示错误提示，避免静默丢数据。

### 4.3 复制、粘贴和删除

- `Delete/Backspace` 删除选中的关键帧，不删除属性本身。
- `Cmd/Ctrl+C` 复制关键帧的属性、值、easing、hold 和相对 frame。
- `Cmd/Ctrl+V` 以当前 CTI 为相对起点粘贴，并按 Item 边界钳制。
- 复制到不同属性时，必须经过显式转换或阻止操作，不能把二维 Position 粘到 Rotation。
- 粘贴后所有新关键帧进入同一个 Undo transaction。

### 4.4 时间轴缩放和滚动

- 缩放中心优先保持鼠标下的 frame 不漂移。
- `zoom` 有明确上下限，不能因为持续滚轮生成无限宽度。
- 纵向滚动同步 Layer panel 和 Keyframe area。
- 横向滚动只影响时间轴右侧，不移动左侧图层列。
- 播放中播放头接近可视区域边缘时自动横向跟随；用户主动横向滚动后暂时停止跟随。

## 5. 状态、异常和边界

### 5.1 必须覆盖的状态

| 状态 | 页面表现 |
| --- | --- |
| 无素材 | 素材区显示上传空状态；关键帧区显示“选择图层后编辑” |
| 有素材无图层 | 资产卡片正常显示，关键帧区不可编辑 |
| 有图层无关键帧 | 显示静态属性和灰色 stopwatch |
| 已开启动画 | stopwatch 高亮，已有关键帧显示菱形 |
| 当前帧有关键帧 | 当前属性菱形高亮，数值来自该关键帧 |
| 当前帧无关键帧 | 数值来自 evaluator，菱形为可新增状态 |
| 正在拖动 | 只显示 transient 位置，未松开不提交 Undo |
| 锁定 | 行和数值不可编辑，关键帧不可拖动 |
| 数据异常 | 保留原数据并标红诊断，不静默清空 |
| 资源加载中 | 关键帧仍可读，涉及资源像素的操作显示加载状态 |

### 5.2 数值边界

- Position：允许负数，不做错误的 `0` 截断。
- Scale：允许正数；零和负数按项目约定阻止或转为最小正数，必须统一。
- Rotation：允许任意角度，显示值可归一化，存储不能丢失多圈旋转信息。
- Opacity：显示范围 `0–100%`，写入时钳制到 `0–1`。
- Frame：只接受有限整数，不接受 `NaN`、`Infinity`、小数或越界值。
- 关键帧数：需要项目级上限；达到上限时阻止新增并给出可理解错误。

### 5.3 不能做的事情

- 不在素材卡片上叠加小型关键帧时间轴。
- 不使用第二个独立 current frame。
- 不在 React render 内自行计算一套插值覆盖 evaluator。
- 不在 Pointer Move 时连续写入 Undo 栈。
- 不因刷新、切换素材页签、播放或重新挂载而丢失展开状态和选中关键帧。
- 不把“不支持”伪装成支持；Expressions、3D、Puppet 等未实现能力必须显式标记。

## 7. 第一阶段实现拆分

### P0：布局和只读展示

- 在素材列表下方增加 `KeyframeInspectorPanel`。
- Timeline 增加 AE 图层列、属性树、时间尺和关键帧只读绘制。
- 当前 frame、选中 Item、选中属性使用现有上下文。
- 交付 `public/keyframe-ae-layout.html` 作为验收样式基线。

### P1：单属性编辑

- Position / Scale / Rotation / Opacity 支持 stopwatch。
- 支持当前帧新增、更新、删除。
- 所有操作进入 Undo/Redo。
- 支持拖动单个关键帧和时间轴缩放。

### P2：多选和数据交换

- 多选关键帧拖动、复制、粘贴、批量删除。
- 对齐 `motion.keyframes` 和 AE exchange package。
- 补充刷新恢复、导入导出、旧 schema 迁移测试。

### P3：其他 AE 排版能力

- Anchor Point、Crop、Audio Levels、Masks、Effects、Parent & Link。
- 每增加一种属性，沿用同一行结构、stopwatch 位置和关键帧交互，不能另起炉灶。
